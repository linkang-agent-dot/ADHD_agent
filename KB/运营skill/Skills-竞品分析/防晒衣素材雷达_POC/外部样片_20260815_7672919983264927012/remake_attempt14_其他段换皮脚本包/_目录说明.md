# 其他段换皮脚本包｜唯一入口

## 本轮只做什么

把已完成“跑跳无痕”之外的原片拆成可单独投喂的换皮段，并按关键帧门禁逐段生成、统一拼回约 30 秒完整成片。

固定口径：原片继续负责人物、动作、机位、场景、运镜、节奏和剪辑；只把画面中可见的深蓝运动内衣换成粉底肤无痕内衣。商品没有露出的段落不重新生成。

## 结论

- 直接复用、不生成：P01A 痛点开场、P05A/P05B 白T正背面结果。
- P02 的跑跳仍复用 `remake_attempt13_jimeng_mini_script_v3/final/P02B_即梦Mini_V3_A_FINAL静音.mp4`；中间插入的背面零痕静态帧观感生硬，已在 V07 起把 8.833–10.033 秒从音画两轨同步切除。
- P01B 商品揭晓内部验收通过：`output/final/P01B_即梦Mini_KF02锁款_FINAL静音.mp4`。首轮仅用白底商品图生成成无肩带抹胸，判退；第二轮先生成双细肩带举稳关键帧，再用“原片视频 + 合格关键帧”重跑后通过。
- P04 冰丝透气与弹力已用个人即梦 Mini 完成：单件商品完成一次横向拉伸并回稳，未再切成两件商品。
- P03 结构讲解、CTA 商品收尾在本轮积分只剩 5 点的条件下，复用历史 API 换皮候选进入完整首版；商品已替换，但人物和原片动作复刻度仍低于即梦段，后续充值后只返这两段。
- 完整拼接版：`output/final/军训粉底肤无痕内衣_完整换皮成片_V02_静音.mp4`。
- 原视频换皮的声音规则已改为“默认完整复用原视频连续声道”。中间商品信息不强塞 TTS，改用原片风格特效字；结尾第二遍“军训必备”已替换为同片无人声环境底轨。当前审片：`output/final/军训粉底肤无痕内衣_完整换皮成片_V14_原声特效字_结构避脸_结尾不复读.mp4`。全程未走公司 GRFal。
- 商品参考一张图只放一个视角、一个商品，不使用双商品拼图；商品展示镜头优先补场景内合格关键帧，不再只靠白底商品图硬赌。
