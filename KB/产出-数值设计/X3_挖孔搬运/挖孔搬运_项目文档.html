① 主循环状态机（界面级，核心）

Idle 待机 ─点格子(过守卫)→ WaitAck 锁输入 ─DigAck→ AnimSeq 动画序列 ─未过关→ Idle  ─stageComplete→ GateAnim 过关演出 → Settlement 结算(挂起切关) ─点空白关闭→ LevelSwitch 切关动画 → Idle(新关)
当前态触发守卫（全过才转移）动作次态
Idle点格子(row,col)非动画中 ∧ 界内 ∧ 非Block ∧ 未挖 ∧ 同格节流200ms ∧ 锄头足够m_IsDigging=true，发 DigReqWaitAck
Idle点格子·锄头不足Level≠1弹礼包（Level==1 只飘字，新手不打扰）Idle
WaitAckAck errCode≠0 / 超时2s—toast + 解锁Idle
WaitAckDigAck 成功—串行动画：①挖开 ②消散∥工具连锁 ③揭示+飞插槽(Delay1.0/Dur0.5)AnimSeq
AnimSeq播完 ∧ !stageComplete—解锁 + 重拉数据刷新（引导光圈重算）Idle
AnimSeq播完 ∧ stageComplete—0.4s 后过关演出GateAnim
GateAnim演出完—弹结算（宝物卡+成色+破纪录标），切关挂起 deferSettlement
Settlement点空白关闭—OnHidden 回调→执行挂起切关：隐旧盘→切关动画→InitGrid→RefreshLevelSwitch→Idle

🔴 两条铁规则：结算弹窗打开期间禁止切关（defer 机制）；WaitAck/AnimSeq 全程输入锁，任何异常路径必须回 Idle 解锁（否则卡死盘面）。

② 格子状态机（单元格级）

Hidden·Normal / Hidden·Special(提示) / Hidden·Premium(惊喜关) / Block(不可点·无监听) ─被挖开(直接点或工具连锁)→ Dug(底图隐藏·清监听) ─所在宝石集齐→ Revealed(footprint 整体消隐)

③ 挂机状态机

NotStarted ─进界面自动发 HangUpStartReq→ Accruing 累计中 ─elapsed≥上限→ Full 已满(红点+tips) ─领取 HangUpRewardReq→ Settle 发奖 ─hangUpTime 重计→ Accruing

🔴 服务端配套：挂机满这类边界时刻必须服务端主动推送 + 登录 OnPostInit 填充 + 重连覆盖——三处缺一个就是"看不到"（页签④/⑨）。

④ 弹窗导航状态机（窗口栈）

主界面 → 结算(模态·关闭回调驱动切关) ｜ → 挂机弹窗 → 商店(二层) → 数量选择(三层) ｜ → 图鉴(全屏·可复用为探测器选择器) ｜ → 探测器(选目标→二次确认→关窗→扫描特效3s) ｜ → 规则 / 奖励预览 / 排行 / 礼包 / 储蓄罐
