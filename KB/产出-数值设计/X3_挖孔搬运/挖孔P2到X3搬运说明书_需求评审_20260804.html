0. 一页结论

挖孔 = P2 最强付费单品（单节 $94.5 万、渗透 44%、单周占大盘中位 15.9%/峰值 42.7%），9 月周年 W2 主力模块，Jira 拆单「周年-挖孔小游戏拓荒搬运」，程序侧原估 10d。

玩法一句话：棋盘挖掘——用锄头点开格子，挖出埋着的宝石图形过关，挖掘过程按配置窗口概率触发工具（整行/整列/3×3 连锁，机制已修正，见顶部提示），关卡无限推进，挂机产锄头/道具，商店+礼包+储蓄罐变现。

搬运源裁决：P2 直搬（新版 NewDigKey）。X2 立过项没做（策划案「X2-第一期开发内容」页签只是需求稿）——所以没有 X2→X3 同源 guid 快捷路，美术/prefab 按 P2→X3 全链路搬运评估（比扭蛋机/限时抢购重）。

核心逻辑已开搬：服务端骨架（ActvType 注册/协议/挖掘+挂机 handler/4 张配置表）已在 feature 分支落地中，详见 §5。

2. 玩法结构速览（给没玩过 P2 挖孔的人）

挖掘循环：进关卡（棋盘 3×3~7×7） → 点格子扣锄头 → 格子下是：宝石碎块 / 工具（触发整行·整列·3×3 连锁挖）/ 空 → 宝石所有占格挖完=揭示 → 全部宝石揭示=过关发奖 → 下一关（无限推进，越深棋盘越大、每格消耗越高）
