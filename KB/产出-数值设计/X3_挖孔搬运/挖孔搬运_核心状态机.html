① 主循环状态机（界面级，核心）

Idle 待机 ─点格子(过守卫)→ WaitAck 锁输入 ─DigAck→ AnimSeq 动画序列 ─未过关→ Idle  ─stageComplete→ GateAnim 过关演出 → Settlement 结算(挂起切关) ─点空白关闭→ LevelSwitch 切关动画 → Idle(新关)
当前态触发守卫（全过才转移）动作次态
Idle点格子(row,col)非动画中 ∧ 界内 ∧ 非Block ∧ 未挖 ∧ 同格节流200ms ∧ 锄头足够m_IsDigging=true，发 DoDigKeysDigReqWaitAck
Idle点格子·锄头不足Level≠1弹礼包（Level==1 只飘字，新手不打扰）Idle
WaitAckAck errCode≠0 / 超时2s—toast + 解锁Idle
WaitAckDigAck 成功—串行动画：①挖开 ②消散∥工具连锁 ③揭示+飞插槽(Delay1.0/Dur0.5)AnimSeq
AnimSeq播完 ∧ !stageComplete—解锁 + 重拉数据刷新（引导光圈重算）Idle
AnimSeq播完 ∧ stageComplete—0.4s 后过关演出(GatePass/Restore)GateAnim
GateAnim演出完—弹结算（宝物卡+成色+破纪录标），切关挂起 deferSettlement
Settlement点空白关闭—OnHidden 回调→执行挂起的切关：隐旧盘→切关动画→InitGrid→RefreshLevelSwitch→Idle

🔴 两条铁规则：结算弹窗打开期间禁止切关（defer 机制，玩家要看到过场）；WaitAck/AnimSeq 全程输入锁 m_IsDigging，任何异常路径必须回 Idle 解锁（否则卡死盘面）。

🔴🔴 08-04 机制修正（工具触发）：上表「工具连锁」的触发源不是格子内容——P2 真配置是按挖掘次数窗口概率投放（tool_trigger：dig_min~dig_max 之间触发 N 次，类型按权重随机），与挖到哪格无关。服务端现实现（工具埋进 boardMap 取 treasureId 负值）待改造，详见项目文档⑧修正① / ④TODO #0。

③ 挂机状态机

NotStarted ─进界面自动发 HangUpStartReq→ Accruing 累计中 ─elapsed≥上限→ Full 已满(红点+tips) ─领取 HangUpRewardReq→ Settle 发奖 ─hangUpTime 重计→ Accruing
态触发/tick动作
NotStartedFormatImplement 检测未挂机自动 DigKeysHangUpStartReq（玩家无感）
Accruing每秒 tick进度环 fill=elapsed/max，文本 hh:mm:ss
Fullelapsed≥HangUpMaxMinutes入口红点亮 + 满提示；收益按 min(elapsed,max) 封顶
Settle领取成功 Ack结算弹窗展示奖励（金币按关卡段×分钟 + 权重池道具）→ hangUpTime=now 回 Accruing

🔴 服务端配套：挂机满这类边界时刻必须服务端主动推送（在线玩家界面不会自己变）+ 登录 OnPostInit 填充 + 重连覆盖——三处缺一个就是"看不到"。

④ 弹窗导航状态机（窗口栈）

主界面 → 结算(模态·关闭回调驱动切关) ｜ → 挂机弹窗 → 商店(二层) → 数量选择(三层) ｜ → 图鉴(全屏·可复用为探测器选择器) ｜ → 探测器(选目标→二次确认→关窗→全屏扫描特效3s) ｜ → 规则 / 奖励预览 / 排行 / 礼包 / 储蓄罐
规则说明
结算弹窗是唯一带副作用关闭的窗OnHidden 必须触发挂起的切关回调——关闭路径只有一条（点空白），别加右上 X 造成第二条路径漏回调
商店入口在挂机弹窗内P2 主界面节点名 BtnShop 其实是挂机入口（历史遗留），X3 重命名避免踩坑
探测器确认前不扣道具开面板不校验；点使用才校验（不足只飘字不关窗）；确认走二次弹窗
图鉴双模式普通浏览模式 / selectMapTarget=true 时点类型直接回调+关窗（当探测器选择器用）
引导仅 Level==1：光圈锁第一个可挖格，每挖一格重算跳下一格；Level≥2 自动消失。无正式引导流程依赖
