§4 结构缺口 —— 要你拍板的部分

① 工具触发机制：表结构还是「埋格」，和定案的「窗口概率投放」冲突 最高优先

现在 Level.ToolIDs 是把工具埋在某个格子里，挖到才触发（服务端也照这个实现）。 但 08-04 从 P2 真配置表得出的结论是：工具按挖掘次数窗口概率投放（dig_min / dig_max / trigger_count / tool_pool 带权重）。

要你定：走窗口概率（则关卡表要删 ToolIDs、加那 4 类字段，服务端同步改），还是就用埋格这个更简单的模型？

连带：挂机表的 ToolItemIDs 现在拿能量铲顶班 —— 三种工具道具（整行 / 整列 / 3×3）还没建 Item 行，等这条定了一起建。

② 关卡只有 3 关，过第 3 关会卡死 阻塞真机跑通

服务端是 levelId += 1，查不到关卡配置就返回 null —— 现在配到 Level 3，第 4 关直接卡住。

已定的编号规划是四类混一张表：1~100 主线 / −1~−15 奖励关 / 9995~9998 特殊地形 / 9999 循环关。 表结构（Level 是 int）支持，但服务端没有任何循环关 / 负数关的处理逻辑。

要你定：这轮是先把 P2 的 119 关真数据整批搬进来（够玩到底），还是先只让程序把 9999 循环关跑通、关卡数据随数值一起定？

③ 主表缺一批指针：界面已经有的模块，配置上没有落点 高

本地化那 84 个键里已经出现了这些模块，但 ActvDigKeys 主表只有 5 个字段，装不下：

  • 探测仪（TXT_ActvDigKeys_BtnStartScanCost）→ 缺「一次扫描消耗什么、多少」
  • 储蓄罐（"每消耗 {0} 个能量铲即可储存 ×1"）→ 缺那个 N，以及储蓄罐奖池
  • 无人机补给站（商店）（ShopTitle / ExchangeLeft）→ 缺兑换表，或者复用 ActvOnline.ShopID（现在是空的）
  • 成就礼包（AchieveTitle / BuyLimit / LevelReq）→ 缺档位表（含限购）
  • 限定纪念卡 3 张（MemLv / MemNext）→ 缺「哪一关发哪张」的映射
  • 图鉴里程奖励（AtlasMileTitle）→ 缺里程档位

要你定：这些各自开新子表，还是尽量复用 X3 现成表（商店走 ShopID、成就礼包走礼包表、纪念卡走 MemorialCard）？复用的话工作量差一个量级，建议逐个过一遍再动手建表。

④ 惊喜关 / 奖励关是同一个东西还是两个？ 中

现在关卡表用 LevelType=1 表示惊喜关；而编号规划里另有「−1~−15 奖励关」是独立的负数 level 行、按窗口随机插入。这两套现在同时存在。

要你定：惊喜关＝奖励关（那就只留一套，删 LevelType 或删负数段），还是确实是两种不同的关？

⑤ 宝物摆放：随机位置 + 随机旋转，对不对？ 中

服务端现在的实现是：全格 Fisher-Yates 打乱 → 逐个宝物找空位放下，还会随机 4 向旋转。也就是同一关每次进来布局都不同。

要你确认：P2 是不是也这样（而不是每关固定坐标）？旋转要不要留？—— 旋转会让"提示格"和玩家心理预期都变化。

⑥ 缺「不可挖格」字段 中

P2 真表有不可挖格（原型 v0.5 用的就是真数据），但关卡表现在只有行列数，服务端把棋盘当满格矩阵；界面文案里还有「特殊地形」标签。

要你定：不可挖格是加一列坐标清单（如 BlockCells="r,c;r,c"），还是靠 9995~9998 那几个「特殊地形」关卡整关预设？

⑧ 道具回收没配（08-06 复查新增）文案与行为不符

道具描述和商店 tip 都写了「活动结束回收」，但 ActvOnline.ItemRecycle(col44) 是空的 —— 活动结束后能量铲/核心电量会留在背包里不回收。既有格式参照：扭蛋机 1211,2100|1212,2100、大转盘 1067,2022（道具ID,回收目标）。

要你定：回收目标折算成什么、比例多少 —— 建议随数值定稿一起配，配之前先把文案里"回收"字样的口径对上。

⑨ 合并预警（自开型窗口）✅ 08-06 已解决

已切生产姿势（commit c2b605d1，导表 #2527 SUCCESS）：TimeController=0 + ActvType 85 进导表 SKIP_TIMECYCLE 集，与扭蛋机(83)/限时抢购(84)同姿势，开窗交给 iGame 逐服部署，测试环境用 gm_combo.py open-activity。 TimeCycle 8501 行保留未删（无人引用即失效，QA 要自开窗口把 col7 指回 8501 即可）。

⑦ 宝物缺品质列、缺图鉴分组列 低（可后补）

prefab 里已经加了品质光节点，程序那边的做法是按占格数推品质（Perfect / Epic / Legendary）；图鉴还有两个页签 + 分组（AtlasTab0/1 / AtlasGroup），表里都没有对应列。

要你定：品质就按占格数推（省一列，但以后想让 1×1 出个稀有款就做不到），还是显式加 Quality 列？图鉴分组同理。
