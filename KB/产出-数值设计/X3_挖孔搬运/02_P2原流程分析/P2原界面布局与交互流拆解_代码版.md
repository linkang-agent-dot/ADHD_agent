## C. 交互流程（玩家动线）

### C-0 进活动
FormatImplement()：打点 UIactv_new_hole_digging → 首进清 HUD 红点 → 拉排行模块 → BGM Play_music_alien_exploration → KeyIcon 模板池隐藏 → 右上资源位初始化（BtnIcon=挖掘道具→ShowPackages 开礼包 / BtnIcon2=探测器道具）→ InitGrid → 本地缓存先刷一帧 → 拉详情(2s超时)再刷 → **未挂机则自动 SendDigKeysHangUpStartReq（进界面即自动开挂机）** → 刷储蓄罐入口。
每秒 tick：倒计时 + 挂机进度环 fillAmount=时长/上限 + 满了亮红点显示 tips20。
红点：挂机满(BtnShop/Tip)、成就礼包(BtnAchieve, 点开清)、探测器、奖励预览、HUD 入口(首进清)。

### C-1 棋盘构建（Board.cs）
Max 8×8；实际 rows/cols 由 MapInfo 下发；小棋盘 rowOffset=(8−rows)/2 居中，多余格关 CellBg 不销毁；非 Block 格才绑 Click→OnCellClick(row,col)；建完 ForceRebuildGridLayout → 对齐锚点 → 协程 WaitForEndOfFrame 后算阴影 bounds 淡入。
格子状态（ApplyCellStyle 切 CellBg 子物体）：Normal / Special(TipsPoints 提示格) / Premium(奖励关整盘) / Block(Disable,不可点) / 已挖(CellBg 整个隐藏+清监听)。

### C-2 点格子（OnCellClick :491）
拦截链：挖掘动画中→拦｜越界→拦｜Block→拦｜已挖→拦｜**同格 200ms 节流**→拦｜道具不足→**Level≠1 直接弹礼包 ShowPackages()，Level==1 只飘字**（新手不打扰）。通过→打点 _dig→m_IsDigging=true→SendNewDigKeysDigReq(row,col)。

### C-4 过关→结算→切关

## 🔶 横转竖关键结论（交互设计优先级排序）
1. **主界面=典型三栏**（左 Slot 485 宽｜中 800×800 棋盘｜右双列按钮栏），棋盘 x+110 右偏是给左栏让位——竖屏归零居中，左右栏改上/下。
2. **最硬的横屏依赖=BtnsDigKey 比例锚 aMin.x=0.8/0.9**（宽度绑死屏宽 10%）：竖屏 1080 下塌缩到 ~108px 装不下 3 个 200px 按钮，必须首先重排。其余节点全是像素锚，改锚点即可。
3. **图鉴翻书=左列表右详情同屏对照，是竖屏体验损失最大的一屏**。建议「上半屏固定详情卡 + 下半屏类型条」保留同屏对照，别拆两级页面。
4. **宝物飞行是横向轨迹（棋盘→左 Slot，约500-700px）**：Slot 挪上/下后飞行改纵向，贝塞尔控制点和 0.5s 时长要重调（纵向距离短，0.5s 显慢）。
5. **背景图 2080×1610 横构图**：竖屏 1080×1920 会露大量空白，必须换竖构图图或改 AutoSizeScaler match——这是美术需求项。
6. 挂机领奖横幅（Content 左右拉满+BtnShop@x=1626）和规则页（Panel1 写死 1920×1080）按 1920 写死，竖屏必改。
7. 商店横向滚动(卡444×648)→改纵向滚动；结算/探测器 2 列 Grid 竖屏反而更优（1080 宽 2 列 ≈500/列，一屏 2×3 张）。
8. **免改清单**：棋盘正方形 800×800 天然适配；工具火箭/炸弹特效方向跟棋盘走不用动；探测器 CenterScrollOn 代码已兼容横竖；结算弹窗结构基本可保。
