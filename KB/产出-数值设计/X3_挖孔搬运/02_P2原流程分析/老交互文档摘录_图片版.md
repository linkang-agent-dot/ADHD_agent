## 一、挖孔优化v86.png —— P2「异星探索」v.86 设计总览板

### 1. 这张图是什么
P2 挖孔小游戏优化版（v.86）的交互设计总览板，深色画板，从上到下三大段：**策划需求 → 交互流程设计（1.活动流程）→ 2.其他界面**。界面主题为"异星探索"（火星沙地挖掘）。

### 2. 主玩法界面布局（横屏结构）
- **顶栏**：左=返回键+标题「异星探索」；中=关卡标签「关卡3」，其下一行小字「本关每次挖掘消耗20个（铲子icon）」；右=两种货币「探测仪币 222,12」「铲子 222,12 +」
- **左栏**：「探索目标」竖版面板，显示本关待挖出道具的**剪影**（黑影+蓝底格子）
- **中央**：约 8×7 的蓝色冰晶方块挖掘棋盘（占屏幕最大区域），挖开处露出沙地
- **右栏（两列图标）**：外列=排行榜 / 奖励预览 / 成就礼包 / 存钱罐 / 装饰好礼；内列=充能中（无人机挂机入口）/ 探索记录 / 探测仪
- 结算、探测目标选择等均为居中弹窗

### 3. 图上标注全文抄录

**【策划需求】**
- 原玩法修改：
  1. 不需要兑换道具，改为在挖掘时触发道具，即刻生效
  2. 进奖励关卡随机送藏宝图。藏宝图使用后可以选择任意一个图鉴内容，下次进入奖励关卡时可挖掘
- 关卡结算界面：
  1. 每次挖完一关后，统计挖到的宝藏，参考钓鱼结算
  2. 每个图鉴下方显示【磨损度】
- 手册界面：
  1. 普通关卡图鉴
  2. 宝藏关卡图鉴
  3. 收集度成就进度条，收集度=普通+宝藏
- 图鉴属性：
  1. 星级-由策划配置
  2. 磨损度：随机刷新的数值词条
- 特效关卡：
  1. 在随机关卡会配置一些带特效的格子，吸引玩家去挖，下方必定有宝藏

### 4. 交互动线
主挖掘 →（挖出目标道具）道具飞入左侧目标栏 →（全部目标完成）结算弹窗 → 道具飞入右栏【探索记录】按钮；右栏探测仪 → 选目标弹窗 → 全屏探测动画 → 右下角"探测中"循环 →（下次特殊关卡）必得指定道具；普通关内挖到特效格→下方必有宝藏；特殊关卡前一关顶部 Tip → 完成进特殊关 → 进场弹窗送探测仪+铲子。

### 5. 对横转竖的启示
- 中央棋盘为正方形-ish（8×7），本身不依赖横屏宽度，可整体保留
- **强依赖横屏宽度的是"左目标栏 + 右两列功能图标"三明治结构**：竖屏需把探索目标改为顶部横条（剪影横排）或可折叠抽屉；右侧 8 个功能入口需收进顶部 icon 行 + 底部工具栏
- 「道具飞入左侧目标栏」「道具飞入探索记录按钮」两条飞行动线的锚点会随布局重排，需重新定义
- 结算/探测/进场弹窗均为居中弹窗，竖屏可直接复用

## ★ 提炼：对 X3 竖屏改造最重要的交互规则

1. **道具"选中→框选范围→拖动定位→确认/取消"三段式**（X2 版）：选中道具栏道具后棋盘出现作用范围高亮框（3×3/整列/整行），移动手指改变位置，出现 ✓/✗ 确认取消，取消回到未选态。这是操作区的核心交互，竖屏必须原样保留且确认按钮要落在拇指区。
2. **消耗与经济闭环**：每次消除消耗 1 个破译装置（P2 版=每次挖掘消耗 20 铲子）；破译装置/电池靠**挂机充电按关卡分档产出（+3/+5/+8/+15 每分钟，6h 上限，可领红点）**，电池在**兑换商店**换 5 种功能道具（垂直消除1400/横向消除1400/3×3消除2800/探底400/指定消除200，各带限购）。活动道具活动结束后回收。
3. **特殊/惊喜关卡的"预告→进入→保底"链**：触发后先在**前一关**弹 Tip/横幅预告（"完成本关后即可进入"），进入时弹奖励弹窗（送探测仪/铲子等，个数策划配置），惊喜关不显示关卡等级、用特殊宝箱；P2 v86 版还叠加**探测仪定向保底**（选图鉴缺失道具→"探测中"循环动画→下次特殊关必得；用过显剪影、没用过显问号）和**特效格必有宝藏**的引导设计。

（其余值得留意：v86 把"先兑换道具再用"改成了"挖掘时触发即刻生效"——道具即挖即用是优化版明确的方向；结算界面每件遗迹带随机"磨损度"词条+个人/全服纪录，是收集向长线钩子。）
