一、现状：核心付费模块只有 3 个

目前能独立扛节日收入的核心付费模块只有开箱、大富翁、转盘这 3 个；其余（竞猜/BP/累充/纪念卡/装饰/每日/周卡/拜访）是辅助货架、流量或外显层。扩覆盖面 = 在这 3 个之外再加能独立扛收入的新核心模块（内外墙抽奖 / 挖孔）。

二、即将规划上线的核心付费形式

8月 马戏节

  • 新增 P2 超凡主城 + 内外墙抽奖（搬运）
    ＝外圈内圈抽奖形式：外圈随机 $19.99 走量拉中小R、内圈固定 $99.99 可复购收鲸（模板 P2 2024 圣诞 GACHA：人均 $153.6/max $8,219/溢出 25.4%）；P2 超凡主城皮肤当大奖载体。这是主城皮肤 + 内外墙形式的首次投放，8 月作效果验证，替掉需求真空的转盘。→ 扩覆盖面①

9月 周年狂欢

  • 新增 P2 挖孔第一版本（形式）+ P2 行军特效（搬运）
    挖孔＝P2 最强付费单品（单节 $94.5 万级 / 渗透 44% / 顶档人均多单），掉落转付费 + 顶档复购的深度引擎；行军特效＝航迹拖尾外显搬运，成套配挖孔/抽奖大奖。→ 增形式③ + 拉坑深②
  • 新增 海妖皮肤系统 & 海妖皮肤抽奖（新内容 + 新系统 + 新皮肤）
    X3 自研海妖 IP：搭一套海妖皮肤系统 + 专属皮肤抽奖，作周年的新外显深度载体（非搬运，纯新增）。→ 四大系统④ + 拉坑深②

10月 万圣节 · 后续待定

  • 待定 P2 弹珠 + 主城皮肤套装系统 + 周年主城
    待 8 月超凡主城 + 内外墙效果验证 后再定：验证成立则弹珠（P2 抽奖形式）扩形式、主城皮肤升级为"套装系统"、补周年主城皮肤。→ ①③④
  • 待定 二游英雄皮肤系统深度优化（皮肤分品质 + 定价拉深度）
    参考二次元游戏英雄皮肤打法：皮肤分品质分层、按品质定价，把英雄皮肤从"一节一款"做成有深度的付费梯队。→ 拉坑深② + 四大系统④
