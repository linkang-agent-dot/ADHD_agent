# X3 节日外显后续议题｜新 Agent 交接

以下两项不混入当前英雄、主城、行军皮肤排期，需要分别开新讨论。

## 议题一：纪念卡强化养成深度

### 已知背景

- 当前问题不是继续加一张“领到即结束”的节日纪念卡，而是让纪念卡形成可持续参与、可追求、可展示的养成深度。
- 需要先盘清现有纪念卡的获取、升级/合成、重复卡消耗、套装收集、外显展示和数值收益，再决定强化哪一层。
- 讨论时应区分：免费参与深度、付费加速深度、排行榜竞争深度，避免把三者揉成一个纯数值坑。

### 请新 Agent 输出

1. 当前纪念卡链路与主要断点。
2. 2–3套深度强化方案，每套写清核心循环、免费/付费边界、重复卡去向、赛季结束后的保留价值。
3. 每套方案的2个北极星指标及风险。
4. 推荐方案与最小可验证版本，不直接改配置。

### 可复制指令

> 继续梳理X3节日外显养成线中的“纪念卡强化养成深度”。先读取现有节日外显全景、纪念卡逐件获取率和节日活动知识库，盘清现状与断点；然后给2–3套方案，明确核心循环、重复卡消耗、免费与付费边界、长期保留价值、2个北极星指标和风险。先做方案讨论，不改配置。

## 议题二：皮肤技能新增主动使用能力

### 已知背景

- 排行榜旗舰英雄皮肤仍是全新节日主题皮肤，不做旧皮肤升级。
- 保留高BUFF、视频展示和高传说人气英雄为主的定位。
- 唯一新增方向：皮肤技能不能只被动生效，需要允许玩家主动激活/使用。
- 这会同时影响技能入口、冷却与次数、战斗公平、技能反馈、跨模式可用范围和皮肤价值感，需先定义产品边界再进入程序与数值方案。

### 请新 Agent 输出

1. 主动技能的使用场景与不可用场景。
2. 入口、触发、冷却、次数、目标选择、成功/失败反馈的完整交互链。
3. 3种技能原型，分别说明强度边界、反制方式和适配英雄。
4. 付费价值与公平性护栏、2个北极星指标、最小可验证版本。
5. 涉及客户端/服务端/配置的改造面清单，不直接实施。

### 可复制指令

> 继续梳理X3节日排行榜旗舰英雄皮肤的“主动技能”方案。前提：做全新节日主题皮肤，不升级旧皮肤；保留视频、最高BUFF和高人气D35前传奇英雄定位；新增能力是皮肤技能可由玩家主动激活。请给完整使用场景、交互链、3种技能原型、强度与公平性护栏、2个北极星指标、MVP和客户端/服务端/配置改造面。先做产品方案，不写代码、不改配置。
