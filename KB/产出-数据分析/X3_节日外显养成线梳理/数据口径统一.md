# X3 节日外显养成线梳理｜数据口径统一

## 本案性质

本案以既有资料盘点为主，并新增一次“其他外显逐件获取率”SQL 快照。历史商业数据仍只用于描述对应窗口，不把不同窗口的绝对量直接做增减归因；2026-08 的马戏节材料主要用于确认配置/投放形态，不用于判断效果强弱。

## 分母与指标说明

- 白皮书饱和度分母：对应窗口的月活超R 18 / 大R 80。
- 其他外显逐件获取率：`成熟服近30日活跃玩家中，历史曾获得该外显的去重人数 / 同服段近30日活跃玩家16,969人`。同一外显的发放 Item 与解锁后实体资产按 `user_id` 去重合并；0%表示当前活跃样本中无获取记录，不直接等同于从未投放。
- 英雄皮肤沿用专项口径：`皮肤曾获得人数 / 对应英雄解锁人数`。英雄覆盖天然不同，因此与上述16,969全局活跃分母不可直接横比。
- D35前英雄按严格边界 `D0≤显示日<D35` 统计。Hero.ShowTimecycleID 为空记为 D0 起显示；`-1` 排除；TriggerType=2 的 `Nd` 按界面第 `N+1` 天标记；TriggerType=6 保留“第N周周M”原文，并用该周最晚服龄判断是否稳定落在 D35 前。该口径是显示池，不是获取漏斗。
- 英雄品质直接取 Hero.Quality，正式映射为 `1普通 / 2稀有 / 3史诗 / 4传奇`。D35前42位实际为稀有7、史诗13、传奇22，本批没有普通品质；英雄品质与皮肤自身的普通/史诗/限定标签是两条独立轴，禁止混写。
- D35区的英雄解锁人数与皮肤获取率沿用2026-07-29成熟服专项快照。本轮已修复专项脚本 `query_trino` 默认100行截断隐患，但因当前运行环境缺少 `DATAIN_API_KEY` 未能重跑；未纳入旧专项查询的零皮肤英雄明确写“未查询”，禁止补0。
- 纪念卡“单期人均约2.5张”：采用07-16完整期真源，深海远航之歌 2,115张 / 861人 = 2.46张/人；不是全卡册长期人均。`X3卡册获取回归_深海世界杯_20260713.md` 的 1,563张 / 623人 = 2.51 是活动未完结的07-13旧快照，不用于本稿当前值。
- 本案不展示跨期收入、ARPU、ARPPU对比，因此不做跨窗三件套结论。
- 免费渠道只用于描述“通过兑换/BP/活动奖励发放”的渠道结构；本案不引用免费发放总量判断优劣。涉及数量时仅使用深海卡的2.46张/人实证。
- 9–12月排期中的$19.99英雄优先级使用2026-07-29英雄解锁人数快照；排行榜英雄除覆盖外还加入主题适配与已有资产复用判断，但未补英雄出战率/偏好前统一标为“候选”，禁止写成已验证人气结论。

- **已上线·有效果证据**：配置/功能上线且有对应回归数据。
- **已上线/配置落地·待效果归因**：已有上线或配置证据，但本案没有模块效果数据。
