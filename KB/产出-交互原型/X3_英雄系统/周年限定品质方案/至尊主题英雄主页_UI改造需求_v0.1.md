# 至尊主题英雄主页 UI 改造需求 v0.1

> 受众关注点：基于现有英雄主页，判断“至尊主题化”能否以换肤和分层方式落地、需要改哪些 prefab/逻辑/配置、成本与风险在哪里。

## 1. 需求结论

在**现有英雄主页**上增加“至尊主题展示态”。玩家查看已完成至尊升级的皮肤时，界面切换为该皮肤配套的主题背景、氛围动效与 UI 皮肤；原有英雄信息、属性、星级、按钮、页签和交互逻辑全部保留。

- 本期验证主题：万圣魔女·哈妮。
- 改造入口：英雄主页。
- 不改入口：皮肤选择页不新增“使用/激活至尊效果”按钮。
- 本需求不包含此前讨论的主动 BUFF 机制。

## 3. 改造范围：已有与新增

| 界面区域 | 当前已有 | 至尊态新增/替换 | 逻辑要求 |
|---|---|---|---|
| 顶部信息区 | 英雄资讯、货币、满级预览 | 仅替换主题色和框体装饰，可不换 | 数据与点击逻辑不变 |
| 英雄标题区 | 品质、英雄名称、兵种/定位标签 | 名称左侧增加小型至尊徽记；标题框可主题化 | 徽记不得遮挡名称、品质和标签 |
| 背景层 | 通用金色大厅 | 完整版：主题静态底图＋循环氛围视频；最小验证版：仅静态底图 | 根据 `SupremeThemeActive` 切换 |
| 氛围装饰层 | 通用大厅装饰 | 月相法阵、烛火、南瓜灯、薄雾、羽毛、魔尘 | 低频运动，不拦截点击 |
| 英雄角色层 | 当前英雄立绘/动态角色 | 沿用英雄展示逻辑；后续可挂至尊形态或大型外显 | 角色面部、姿势与交互能力不得因 UI 换肤丢失 |
| 左右快捷入口 | 陌生、排名、皮肤、GM 等 | 图标外框及底座允许主题化 | 位置、数量、热区和跳转不变 |
| 星级区域 | 角色下方星级展示 | 完整保留 | 任何新增徽记、粒子、角色部件均不得遮挡 |
| 等级/属性区 | 等级、战力、兵种属性、升级按钮 | 面板底框、分割线、按钮外皮可主题化 | 数值、排版顺序、按钮状态不变 |
| 底部导航 | 等级、星级、技能、装备 | 页签底板、选中态外皮可主题化 | 节点数量、选中逻辑和红点逻辑不变 |

## 4. 推荐界面分层

从后到前：

1. `ThemeStaticBg`：主题静态底图，同时作为首帧、加载占位和低性能降级图。
2. `ThemeVideoBg`：6–10 秒无缝循环氛围视频；默认静音；加载成功后淡入覆盖静态图。
3. `ThemeAmbientFx`：低频粒子与局部循环特效，不接收 Raycast。
4. `HeroDisplay`：沿用现有英雄立绘/Spine/视频展示节点。
5. `HeroForegroundFx`：少量角色前景魔尘或羽毛，不得覆盖脸、名称、星级及按钮。
6. `ExistingUIRoot`：现有数据、按钮与交互节点。
7. `ThemeUISkin`：现有框体和页签的主题 Sprite 替换；尽量换图，不重建业务节点。

## 5. 至尊徽记规则

- 锚点：英雄名称左侧，与名称同一水平层级。
- 定位语义：品质前缀，不是页面主视觉。
- 尺寸：不得高于名称栏主体高度，不挤压英雄名称的安全显示宽度。
- 禁止区域：角色立绘中央、星级区、属性区、按钮区、页签区。
- 当名称较长时：优先保持徽记与名称间距，名称继续使用项目既有多语言缩放/Best Fit 规则。

## 6. 背景视频行为

- 进入至尊英雄主页：先显示静态底图，视频准备完成后 200–300ms 淡入。
- 循环内容：月相缓慢转动、烛火摇曳、南瓜灯呼吸、薄雾平移、少量羽毛或魔尘漂浮。
- 禁止：镜头晃动、快速闪白、高频粒子、大面积明暗跳变。
- 离开页面、切换非至尊皮肤、应用进入后台：停止播放并释放或进入项目统一缓存策略。
- 视频加载失败或设备降级：持续使用静态底图，界面功能不能受影响。
- 所有视频与特效节点必须关闭 Raycast，不能挡住现有按钮。

## 7. 状态切换

统一状态定义：

- `SupremeUnlocked`：玩家已完成该皮肤的至尊升级。
- `SupremeAppearanceSelected`：当前英雄正在展示该皮肤的至尊形态，而非回退后的传说形态。
- `SupremeThemeActive = SupremeUnlocked && SupremeAppearanceSelected`：只有该条件为真时，开启至尊主题背景、视频、氛围特效、主题 UI 和徽记。

| 状态 | 表现 |
|---|---|
| 非至尊皮肤 | 完整沿用当前英雄主页 |
| `SupremeThemeActive = true` | 开启主题背景、视频、主题 UI、至尊徽记及配套氛围表现 |
| 已拥有至尊、切回传说外观 | `SupremeAppearanceSelected = false`，主题背景、视频、主题 UI 和徽记全部关闭，恢复普通英雄主页 |
| 资源加载中 | 静态主题底图＋现有 UI，角色与操作正常 |
| 视频/特效加载失败 | 静态主题底图降级，不弹错误打断玩家 |

## 8. 资源需求

- 1 张主题静态背景图。
- 1 条 6–10 秒无缝循环氛围视频。
- 1 套主题 UI Sprite：标题框、左右入口底座、等级/属性面板、底部页签、升级按钮外皮。
- 1 个至尊徽记小图标。
- 若无法全部换肤：优先级为背景与氛围 ＞ 标题/徽记 ＞ 底部页签 ＞ 属性分割线。

分期口径：

- 最小验证版：静态背景、至尊徽记、标题区与底部页签换肤，用于验证主题切换链路。
- 完整版：在最小验证版上补齐循环背景视频、氛围特效及全部主题 UI Sprite。视频是完整版必做资源，不再作为可选项。

## 9. 实现建议

- 优先保留英雄主页现有 prefab 层级和 Auto 绑定，采用新增主题容器＋原节点 Sprite 替换，避免复制一套业务界面。
- 主题资源尽量配置驱动：以“当前展示皮肤/至尊状态 → ThemeID → 背景、视频、UI Sprite、徽记、氛围特效”映射。
- 背景可优先评估复用项目现有 `EffectDisplay` 的 VideoDisplayKey/DisplayKey 能力；若现有英雄主页没有对应节点，再增加纯展示节点。
- 全屏背景继续使用项目现有适配组件；新增装饰节点不得复制带 `RectTransformScaler` 的背景节点，避免缩放被持续接管。
- 不改变现有按钮节点名、业务绑定字段、红点节点及点击事件路径。

### 9.1 建议数据契约（供实现 Agent 对照现有配置评估）

> 表名和落表位置由实现 Agent结合现有皮肤配置链路确定；以下是功能所需最小字段，不代表已存在同名字段。

| 字段 | 类型 | 必填 | 含义 | 默认/降级 |
|---|---|---|---|---|
| `SkinID` | int | 是 | 绑定的至尊皮肤 ID | 无匹配则不启用主题 |
| `ThemeID` | int/string | 是 | 至尊主题资源组标识 | 空则使用普通英雄主页 |
| `StaticBgDK` | string | 是 | 静态背景 DisplayKey | 资源失败则使用普通背景 |
| `VideoDK` | string | 完整版是 | 循环背景视频 DisplayKey | 失败时保持静态背景 |
| `UISkinID` | int/string | 是 | 标题、入口、面板、页签的主题 Sprite 组 | 缺失项逐项回退普通 Sprite |
| `BadgeDK` | string | 是 | 名称左侧至尊徽记 | 缺失时不显示徽记 |
| `AmbientFxDK` | string | 完整版是 | 氛围特效资源 | 失败时不播放，不影响操作 |

### 9.2 本地化、数值、埋点与日志

- 本地化：本轮不新增显示文案和 TextKey；至尊徽记为纯图标。既有英雄名称、品质、按钮与属性文字继续走原链路。
- 数值：本轮只改表现层，不新增或修改属性数值、升级消耗及战力计算。
- 埋点：最小验证版不新增业务埋点；若项目已有英雄页/皮肤切换埋点，应保持事件和参数不变。
- 日志：开发调试期建议记录一次主题资源加载失败及降级原因，正式环境按现有资源加载日志策略处理，禁止循环刷屏。

## 10. 给实现评估 Agent 的必答项

1. 当前英雄主页对应的 prefab、业务类与 Auto 绑定类分别是什么？
2. 当前角色展示使用 Spine、视频还是其他 `EffectDisplay` 链路？能否直接承载至尊形态？
3. 背景视频是否可复用现有 VideoDisplayKey；生命周期与内存释放是否已有范式？
4. 主题 UI 能否只换 Sprite/DK，还是必须新增一套节点？
5. “当前展示皮肤 → ThemeID”已有配置入口吗；若没有，最小新增字段或映射表放哪里？
6. 哪些现有动画、Scaler 或 Layout 组件会接管位置/尺寸，可能导致主题节点错位？
7. 给出最小可行版本、完整版各自的改动文件、工期级别和主要风险。

## 11. 验收标准

- 原界面所有数值、文字、按钮、红点、跳转和页签切换均可正常使用。
- 至尊徽记位于英雄名称左侧；星级完整可见，无遮挡。
- 背景视频与氛围特效不接收点击，不影响任何现有热区。
- 非至尊皮肤显示与改造前一致，不残留主题资源。
- 主题资源未加载或视频播放失败时，可稳定降级到静态背景。
- 1080×1920 设计基准下构图成立；长屏、刘海屏按现有 Safe Area 与背景 Expand 规则适配。
- 连续切换英雄、皮肤与底部页签，不出现视频叠播、主题残留、闪黑或资源泄漏。

### 11.1 可执行验收步骤

1. 在至尊与非至尊皮肤之间连续切换 20 次：同一时刻最多播放 1 条背景视频；普通皮肤下无任何至尊节点残留。
2. 在至尊页面停留 10 分钟：视频首尾衔接无明显跳帧、无声音、界面按钮持续可点击。
3. 模拟 `VideoDK` 加载失败：静态背景持续显示，页面无黑屏、无阻塞弹窗。
4. 逐个点击现有左右入口、升级按钮和四个底部页签：点击结果与改造前一致。
5. 对照当前英雄主页检查所有星级、数值和红点：位置与可读性不低于改造前，至尊徽记仅出现在名称左侧。
6. 切到后台再返回：视频按项目生命周期恢复或重播，不出现双音轨、双实例或黑帧。

## 12. 本轮不做

- 不新增皮肤选择页“使用至尊效果”按钮。
- 不改英雄养成、属性计算、升星和升级业务。
- 不实现至尊获取、付费和升级流程。
- 不实现主动 BUFF。
- 不在本轮确定翅膀、机甲等角色资产的最终制作规格。
