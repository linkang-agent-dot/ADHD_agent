- 梯度方向：品质越高，不只提升立绘动态程度，还逐级增加“互动、场景、社交身份、界面主题化”的覆盖范围。

  - “传说·动态互动限定”是传说最高档，还是独立的周年/排行榜限定品质。
  - “脱衣互动”的具体尺度、触发入口、重复观看方式及内容安全标准。
  - 英雄选择界面替换范围是仅背景，还是背景、边框、按钮、页签、转场和音效整套替换。

## 2026-08-06｜传说动态皮肤主题选择方向

- 需要为“传说·动态”档单独框定可选主题方向，避免每期凭感觉选题。
- 收尾时需要形成：
  - 主题分类池：哪些幻想与审美方向允许进入传说动态档。
  - 准入标准：什么主题值得投入动态表现和配套头像框。
  - 排除标准：哪些题材只能做普通静态皮肤，不能占用传说动态资源。
  - 角色适配：主题与英雄人设、体型、职业、玩家偏好的匹配规则。
  - 节日适配：常驻主题与周年、情人节、万圣节等节日限定主题如何区分。
  - 重复控制：相邻皮肤在色系、服装轮廓、场景幻想和互动卖点上的避重规则。
- 当前状态：**待收尾时具体框定**

## 2026-08-06｜三档与四档的关系方向 A：同皮肤基础版 → 完整版

- 四档是原三档的纵向延伸，不是另做一张互不相关的皮肤。
- 玩家获取三档后，获得的是该主题皮肤的**基础版**：
  - 传说动态皮肤本体
  - 当前等级的专属主题表现
  - 基础配套头像框
- 四档是同一张皮肤的**完整版**：
  - 在基础版之上追加专属互动露出
  - 脱衣互动
  - 配套场景替换
  - 完整头像框、头衔、聊天表情
  - 英雄选择界面背景及配套 UI 整体替换
- 核心关系：玩家不是重复获得两张皮肤，而是把已拥有的三档皮肤继续补全为完整主题套装。
- 当前状态：**方向 A，待与方向 B 对比**
- 待收尾时确认：升级所需获取方式、重复获得补偿、基础版与完整版是否可自由切换、完整版资产是否拆分获取。

## 2026-08-06｜三档与四档的关系方向 B：两张独立皮肤

- 三档与四档分别作为独立皮肤出现，各自拥有明确品质与完整内容，不存在基础版升级到完整版的关系。
- 三档：独立的传说动态皮肤。
- 四档：独立的传说动态互动限定皮肤。
- 方向 B 的主要好处：
  - 玩家对品质档位和商品定义的理解更直接。
  - 每张皮肤“获得即完整”，不会产生基础版残缺感。
  - 获取、展示、复刻、补发和配置关系更清楚。
- 当前状态：**方向 B，待与方向 A 对比拍板**

### 两个方向的核心取舍（当前原始判断）

| 方向 | 核心优势 | 核心风险/待验证 |
|---|---|---|
| A：同皮肤基础版 → 完整版 | 形成类似“套装补全/追阶”的概念；玩家已获得三档后，会产生继续向四档冲刺的动力 | 三档可能被理解成残缺版；升级、重复获得、资产拆分和展示规则更复杂 |
| B：三档、四档独立皮肤 | 玩家定义更清晰；两档产品边界、获得结果和展示逻辑更直接 | 三档对四档的追逐动力较弱；需要分别建立两套足够差异化的主题价值 |

- 当前状态：**两方向均保留，暂不推荐或拍板**

## 2026-08-06｜方向初判（助手建议，未拍板）

- 当前信息足够做方向级判断，但不足以完成商业化与实现定案。
- 初步更推荐方向 A，但不建议对玩家称为“基础版 / 完整版”：
  - 三档应被定义为一张内容完整、可以独立成立的“传说动态皮肤”。
  - 四档应被定义为基于同主题追加的“典藏主题套装/主题升格”，而不是补完残缺皮肤。
  - 对内关系是同主题纵向升级；对外感知是“完整皮肤 + 可继续追求的典藏套装”。
- 推荐原因：
  - 保留玩家获得三档后继续向四档冲刺的动力。
  - 与头像框、头衔、聊天表情、互动和界面主题化的“套装补全”逻辑一致。
  - 相比两张独立皮肤，不需要同时建立两套完全不同的角色幻想与主题资产。
- 方向 A 成立的必要条件：
  - 三档单独看必须完整，不能故意拆掉核心表现制造残缺感。
  - 四档只追加主题升格内容，不重复收取三档已有价值。
  - 玩家从三档冲四档时，三档的已投入需要被继承、抵扣或计入进度。
  - 收藏页用同一皮肤条目表达“传说动态 / 典藏套装已解锁”，避免出现两张近似卡。
- 最终拍板仍缺：三档与四档获取方式、目标付费人群、成本差、能否直接获得四档、旧皮肤数据结构是否支持升级态、复刻与补发规则。

## 2026-08-06｜方向 A 收敛：至尊升级

- 对外名称：**至尊升级**。
- 产品关系：玩家先获得完整的“传说动态皮肤”，再对同一皮肤进行“至尊升级”；不是重新获得第二张皮肤。
- 界面必须提供“至尊升级预览”，至少能提前看到以下变化：
  - 专属互动场景
  - 专属主题 UI
  - 属性提升：幅度较弱、以品质与身份象征为主，不作为主要购买理由
- 升级预览的作用：先把至尊升级后的差异完整展示给玩家，再承接升级获取行为。
- 当前判断：**方向 A 基本确认，暂未正式收尾**。
- 剩余核心定义：传说动态皮肤升级到至尊后，角色服装与动态表现分别调整到什么范围。

### 待定义：传说 → 至尊的外观升级边界

- 服装调整范围：配色变化、材质升级、局部配饰增加、服装结构变化、可脱/可切换部件分别做到哪一层。
- 动态调整范围：基础待机、循环动态、点击反馈、专属互动、出场演出、场景联动分别新增或替换哪些内容。
- 对比要求：玩家在升级预览中必须能一眼看出变化，不能只靠文字和属性数值解释。
- 兼容要求：至尊状态是否允许切回传说外观、互动场景是否可独立开关、主题 UI 是否跟随穿戴状态，需要在收尾时拍板。

- 初步边界判断：
  - **服装差异负责让玩家看出“升级了”。**
  - **场景、互动和 UI 差异负责让玩家相信“这是至尊”。**
- 当前状态：**作为竞品证据与范围参考，待收尾时并入传说/至尊定义。**

## 2026-08-06｜至尊英雄页背景采用氛围视频循环

- 至尊升级后的英雄选择/英雄主页背景，不只替换静态背景图，可使用类似“装饰阶梯礼包”的氛围视频无缝循环播放。
- 分层方式：
  - 底层：主题氛围视频循环。
  - 中层：英雄角色与专属互动表现。
  - 上层：英雄信息、属性、按钮与至尊主题 UI；保持可点击且不受视频层影响。
- 万圣魔女示例可动元素：月相法阵缓慢旋转、烛火摇曳、南瓜灯呼吸、薄雾移动、少量羽毛与魔尘漂浮。
- 动效原则：低频、低位移、无镜头晃动，不与角色动态争夺焦点。
- 建议规格：6–10 秒无缝循环；默认静音；首尾帧连续；进入页面淡入，离开页面停止播放。
- 性能与降级：静态效果图兼作首帧、加载占位与低性能降级图；视频未就绪或播放失败时不影响界面操作。
- 当前状态：**方向认可，具体视频内容与技术规格待收尾时确认。**
## 新增待评估元素：翅膀与机甲

- 翅膀：可作为“传说 → 至尊升级”中改变角色外轮廓的核心大元素，单独验证展开面积、层级、主题融合度及高阶识别度；避免仅作为背部小挂件。
- 机甲：可作为独立的至尊主题方向，以“人物基础皮肤 + 可展开机甲套装”建立升级关系，重点验证外骨骼、动力翼、浮游装甲和机械臂带来的体量差。
- 当前状态：两项均先出单元素概念图评估，暂不并入最终方案定稿。

## 至尊徽记的界面位置约束

- 至尊徽记可以保留，但应缩小并放在英雄名称左侧，作为名称栏中的品质前缀。
- 禁止把新增徽记放在角色下方中央或星级展示区域，不能遮挡既有星级、数值及任何功能信息。
- 至尊感主要由角色升格、场景、动态和主题 UI 共同表达，徽记只负责身份确认，不承担主视觉表现。

## 至尊系统闭环：最终形态、专属互动与升级预览

> 阶段说明：当前仍处于产品方案讨论期。以下按钮位置、入口复用和流程描述仅是 UX 草案，不作为定案；需要先确定至尊系统的内容结构、价值构成和状态关系，再进入 UX 设计。

- 暂不考虑翅膀元素，先完成系统逻辑闭环。
- 至尊最终形态：英雄主页整体切换为该皮肤的主题背景、氛围表现和配套 UI 皮肤。
- 最终形态需要新增一个“专属互动”入口；建议占用英雄主页右侧纵向入口区，在“皮肤”按钮下方新增同规格小型圆形按钮，不使用大按钮，不遮挡角色与属性。
- 专属互动按钮仅在至尊最终形态下显示；点击进入独立的主题互动场景，退出后返回至尊英雄主页。
- 系统还需要一条面向未解锁玩家的预览流程，让玩家在升级前看懂：角色/形态变化、主题背景与 UI、专属互动、配套身份外显。
- 建议同一入口按状态复用：未解锁时显示“至尊预览”，解锁并展示至尊形态后显示“专属互动”。
- 待确认的关键状态：至尊预览是所有玩家可见，还是仅拥有传说动态皮肤的玩家可见。

### 当前方案阶段先讨论

- 至尊升级的核心价值由哪些内容组成，哪些是固定标配、哪些按主题选配。
- “最终形态”与传说形态的关系：纯追加、形态切换，还是可分别穿戴。
- 专属互动属于至尊固定标配，还是部分限定主题才具备。
- 预览需要向玩家证明哪些价值，但暂不讨论具体页面、按钮位置和点击流程。
- 获取、升级、继承与复刻规则。

## 抽奖获取与至尊晋升 Demo 的正确职责

- 抽奖获取模块不能只负责抽取操作；界面内需要支持“传说基础版 / 至尊版”切换展示。
- 基础版和至尊版均应支持预览，让玩家抽取前直接理解外观与内容差异。
- 晋升模块必须优先解释规则：基础皮肤如何晋升至尊、消耗什么、已有投入如何继承、当前进度及完成后获得什么。
- “抽到基础皮肤后直接跳晋升页”仅可作为完成抽取后的引导，不是两个模块的核心结构。

## 至尊晋升规则方向：主题套装集齐制

- 至尊晋升不采用单一材料累计，而是拆成多个有独立名称与展示价值的主题组件。
- 当前组件示例：
  - 至尊勋章
  - 主题头像框
  - 高级皮肤：角色主体换装/形态升级
- 玩家集齐全部指定组件后，自动完成至尊晋升，并额外解锁系统级最终包装：
  - 英雄主页主题 UI 替换
  - 专属英雄皮肤背景
- 产品结构：抽奖池产出可单独识别的套装部件；晋升不是再消耗部件，而是检测收藏条件达成后直接解锁最终形态。
- 相比单材料进度条的优势：每次获得都有明确内容价值，套装目标更具收藏感，集齐时形成清晰的完成仪式。
- 待确认：专属互动是随“高级皮肤”单件解锁，还是作为集齐套装后的最终奖励一并解锁。

### 专属互动的提前展示规则

- 专属互动正式使用权仍属于至尊套装集齐奖励。
- 即使玩家尚未解锁至尊，皮肤界面也必须展示专属互动入口；入口显示锁态，点击可查看互动预览。
- 完成至尊晋升后，同一入口去锁并开放完整互动，避免解锁前后入口位置和认知发生变化。
- 目的：互动是至尊价值的重要证明，必须在购买与收集阶段提前露出，不能等玩家集齐后才第一次看到。
