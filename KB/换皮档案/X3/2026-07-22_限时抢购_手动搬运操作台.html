3.5换皮无忧去重（跑 3 次，只换「资源目录」）

🔴 唯一的危险在「资源目录」这个字段 —— 只能填本次搬运的专属目录。 它的删除范围＝该目录内所有「根 prefab 没引用到的」文件，无差别删。 2026-07-31 真事故：这个字段填成共享目录 Res/UI/Prefab/Activity（含 256 个 X3 原生件）→ 删掉 143 个 X3 原生 prefab（286 文件）。 断链路线的 prefab [Prefabs 0]＝不引用任何 prefab ⇒ 同目录所有 prefab 全成「未引用」全灭。
共同步骤：Project 里选中 FlashSale.prefab → Tools ▸ Prefab换皮 → 「根 Prefab」会自动填好 → 资源目录：Project 里右键那个文件夹 → Copy Path（Alt+Ctrl+C） → 粘进字段 → 先点「预览」 → 看清 将删 N → 再「执行清理」。
⏱ 它很慢（分钟级），Unity 会挂 Hold on (busy for 58s…)，别以为卡死，也别在里面点别的。
预览是唯一的后悔机会 —— 看 将删 N 这个数字：
N = 0～2 → 正常，可以执行
N = 几十／几百 → 立刻停手，目录填错了，别点执行

6亲眼看上次的翻车点

选中 Content/Grid/Item1/BoxNormal/Card/Icon，看 Inspector

你会看到这个节点上挂了 3 个组件：一个 TFWImage（底图）+ 2 个 X2 的 item 显示组件。 后面这两个会按自己的默认数据画「LV99 头像 + 555」，把底图盖掉。

上次代码走 SetItemBasicInfo(道具, 底图) 只设了底图 sprite → 8 个格子图标全一样、数量全是 555。正解 = 调那 2 个 item 组件的 SetItem(itemId)，不要去设底图 sprite。

这一眼就是手动做的全部意义 —— 脚本化迁移看不见「一个节点上叠了 3 个画图组件」。
