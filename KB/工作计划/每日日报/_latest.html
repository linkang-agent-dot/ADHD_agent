■ 3. X3 马戏扭蛋机数值复核（用户反馈"感觉有点奇怪"）

查出三处真问题：

  • 抽 10 次有 5.7 次是同一个东西——付费池某一项命中率 56.8%、占全池期望值 52.3%。根子在 07-21 那次"七行砍到六行"：删掉一行、权重并进同类行，期望值分文不差，但视觉多样性砍半。当时只验了期望值没验命中分布。
  • 同一个界面里两套券包价差 1.8 倍，浮动随机包还额外白送等量的币，买锚点包的玩家纯吃亏。
  • 浮动包实际 664%，不是记录在案的 480%——07-28 追加等量扭蛋币那一步没重算。

终态（已上线）：付费池 782% → 700.2%，免费池 102% → 147.2%，免付比 21.0%；

最高单项命中率 56.8% → 35.5%，用户说的"抽起来奇怪"根因解决；两池各喂一条养成线

（付费给海妖经验、免费给英雄经验，啤酒这种不计价的换掉）；砍神秘金属保留外圈券。

硬约束：每池 6 行是被 prefab 的 3 列×2 行卡死的，所以是"行数 / 期望值 / 低重复率三选二"。

沉淀的通用规律：EV 守恒 ≠ 体验守恒——删奖池行把权重匀给同类行，期望值校验完全看不出问题。

另：给开箱奖池加了 10% 的勋章档位，每抽勋章产出 3.50 → 4.25（+21.4%），其余项相对收紧。

■ 13. X3 半年 / 9-10 月节日规划（今早与 leader 对齐后的要求）

用户要求：规划拉到半年、内容更细、结合 P2 数据评估"加东西的效果和工作量"，

并明确目标 = 付费占比 40-50%。

先把口径定死（这一步决定后面所有算法）：用户拍板不看 ARPU，看模块当周收入占当周大盘——

这个口径的好处是各模块的周占比能直接加总成 40-50% 的目标。

拉出的关键数：挖孔中位 15.9% / 峰值 42.7%，弹珠中位 9.7% / 峰值 26.9%，

累计收入 141.7 万 : 74.6 万 = 1.9 : 1。

三条宏观结论：

  • X3 单模块其实不弱——夏日开箱单周做到 15.2%，已摸到 P2 挖孔的中位线。差的不是模块质量，是一周只有一个模块在打。
  • 真正的窟窿是空窗——X3 有 3 个整周节日占比掉到 0.3-0.6%，而 P2 常年 40-58%。空窗周大盘照常，节日一分没拿到，补这个不需要任何新玩法。

先把口径定死（这一步决定后面所有算法）：用户拍板**不看 ARPU，看模块当周收入占当周大盘**——

 · X3 单模块其实不弱——夏日开箱单周做到 15.2%，已摸到 P2 挖孔的中位线。差的不是模块质量，
   是一周只有一个模块在打。
 · **真正的窟窿是空窗**——X3 有 3 个整周节日占比掉到 0.3-0.6%，而 P2 常年 40-58%。
   空窗周大盘照常，节日一分没拿到，补这个不需要任何新玩法。
 · 40-50% 的凑法是"每周有个 15%+ 的主力顶着再叠辅助层"，不是把单个模块做到 50%。
拆解成三段：排满日历（+5~7pt，零开发）→ 形式改造（+7~13pt，约 9 天）→ 新玩法（+8~14pt，17 天+）。
