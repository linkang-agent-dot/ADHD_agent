# 马戏节皮肤「猛兽驯服者·阿米娜」· 换装演出视频脚本

> 2026-07-27 定稿方向。皮肤主题=**魔术师**，主色=**深紫+金**（红黑金已废，理由见 `_马戏节_英雄皮肤设计brief_庆典x性张力.md`「配色与主题改版」段）。

## 🔄 方向调整（2026-07-28 用户拍板，覆盖下方 §一 的 A/B 设定）

> **原方案**：A(全扣正装) 出场 → 变 → B(敞开演出装)。
> **现方案**：**B(敞开版 alt1) 才是出场造型** → 表演 → **脱掉外套** → **内搭变成纯金为主**。

**为什么改**：用户判断——"上来穿太多了不行"。开箱大奖皮肤的**静态图要承担付费转化**，商店/图鉴第一眼就得有看头，全扣起来的 A 太端着。**戏剧反差要让位于第一眼吸引力。**

| 出场造型（＝三件静态图） | `Amina_Magician_A_purple_v1_alt1.png`（敞开长外套+内搭，深紫为主·金为辅） |
| 脱外套后 | **内搭纯金为主**（主辅色调换），只存在于视频里，**不单独出主稿**、交给 seedance 发挥 |

### 纯金内搭的四个坑（写进 prompt 时必防）
1. **大面积纯金显廉价**（死金＝塑料感/土豪金）→ 靠层次：亮金高光＋暗金古铜压阴影；材质分缎面金（大面积）／金属亮片（点缀）／半透明金纱（飘动）
2. **要留少量深紫当锚**——全金会跟出场造型断联系、认不出是同一角色的两形态 → choker／丝袜／靴子／飘纱渐变里保留紫
3. **需要暗色压场**——大面积金无暗色压制会整体"飘" → **保留 alt1 的黑丝袜**（黑金经典对比，正好当压场暗色）
4. **红发在金上会糊**——深紫底上红发极跳，纯金是邻近色易糊成一片 → 靠明度差（金够亮／红发保持深红）＋颈肩处放深色元素（choker／肩章）做分隔

### 脱外套＝减体量，必须用加法补
alt1 的大摆长外套占画面面积很大，只脱不加会让人物"缩水"、画面变空，观感是**变简陋**而非变华丽。补法：
**纯金材质升级（主）＋ 飘动轻元素（薄纱披帛／长飘带，补体量且会动）＋ 马戏装饰（羽饰／流苏／珠链）＋ 头发散落（补头部体积）**。四样一起，"脱"才变成"绽放"。
**礼帽保留**（魔术师识别符，全摘没那味了）；想强化释放感可让它留到最后一拍再摘。

## 一、演出核心：是「变」不是「脱」
> ⚠️下方 §一~§三 写于方向调整前，A/B 的具体所指以上面「方向调整」为准；但「变≠脱」「材质吸光vs反光」「媚≠卖骚」三条判断依然成立。

用户拍板的关键判断：**外套消散后不是少一层衣服，而是整体风格切换**——"更给人一种风格改变的感觉，变得更露一些，比纯脱有意思得多"。

所以演出的信息量落在这几个维度的**同时切换**上，不是衣服件数的减法：

| 维度 | 造型 A（进场·正装） | 造型 B（变化后·演出装） |
|---|---|---|
| 廓形 | 硬挺、包裹、大 | 贴身、流动、轻 |
| 材质 | 哑光丝绒（**吸光**） | 缎面珠光（**反光**） |
| 头发 | 束起/盘发 | 散落 |
| 气质 | 端庄、有距离、权威 | 妖冶、放松、带笑 |
| 露出 | 几乎不露 | 腿与背（半透元素半遮） |

★**材质那行是隐藏王牌**：舞台灯下 A 不发光、B 会发光，视频里的观感是"整个人亮起来了"，比单纯少件衣服有戏得多。

★**尺度线**（沿用 brief §五）：媚≠卖骚。媚靠剪裁、材质、遮挡；卖骚靠裸露面积。B 露腿与背，**胸依然包住**，撑场面的是风格反差不是裸露量。对标碧蓝「晚宴礼服档」，不碰被下架线。

## 二、循环处理：不做无缝，用满屏特效遮切点

用户拍板：**不需要无缝循环，播完回到开头进场态即可**。

客户端播放链路是循环播整条的，硬切会有跳变——但**让结尾特效漫过全屏**就能免费藏掉：紫烟涌起铺满画面那一帧切回开头，跳变被完全遮住，观感等同电影转场。**纯画面设计解决，程序零改动。**

> 这一条放宽了 [[reference_x3_hero_skin_video_production]] 第八章「首尾帧必须一致」的约束——那是为无缝循环服务的，本案不需要。但「一条直出禁拼接」的铁律仍然有效。

## 三、分镜（喂 seedance 用）

一条直出，约 8-10s：

1. **起手**：站定，紫金正装，手扶帽檐，目光斜下 → 抬眼看镜头，了然一笑（眼神给镜头＝死活线）
2. **施法**：指尖捻住翻领，打一个响指 → 紫金光尘自下摆升起
3. **变身**（★token 预算砸这段）：光尘上涌漫过全身，正装解体消散；光尘散尽时已是演出装——**发丝散落、材质由哑光转为缎面高光、轻盈元素开始飘动**
4. **定格**：侧身撑胯，目光扫向镜头，这是最值钱的一拍
5. **收尾**：紫烟自四周涌起漫过全屏（＝切点遮蔽）

### 调参旋钮（每轮只改一处）
- 变身段吃不吃力 → 该段措辞加/减；模型爱丢的就是这段，token 优先给它
- B 造型太保守/太露 → 调 `glamorous stage performer` 的修饰词，或显式加/去 `translucent fabric`
- 收尾烟雾不够满屏 → `floods the entire frame` 加强为 `completely fills and covers the whole screen`
- 时长不够 → 砍前段动作内容（模型按内容量铺时长，写秒数没用）

## 五、技术约束速查（别踩）

- **模型选 seedance**：kling 给 2D 立绘的脸必张嘴/warp 且压不动（撞墙 6 版实证）；seedance 脸稳+运动量够。
- **一条直出，禁拼接**（用户历史铁律，拼接缝的光影漂移被毙过两次）。

>

## 六·五、分镜终版（2026-07-28 定）

1. **出场**：紫金魔术师站定，手扶帽檐，目光低垂 → 抬眼看镜头，了然一笑
2. **施法**：捻住翻领，打一个响指 → 紫色光尘沿外套燃起
3. **变身**（★核心，token 预算砸这段）：紫外套化烟消散 → 显露**金色演出装**（＝造型C参考图：金胸衣/金手套/金长靴/黑蕾丝丝袜/**礼帽仍在**/红发散落带辫）
4. **收尾**：落定撑胯站姿 → **一个缓慢的 wink → 指尖触唇送出飞吻**
5. **切点遮蔽**：紫烟自四周涌起漫过全屏

> **收尾动作定为 wink+飞吻的经过**：先提过「摘帽谢幕＋wink＋戴回帽子」（好处是戴回帽子＝回到出场姿态、循环衔接更顺），
> 用户否决——"摘帽没什么意思，还是得有点性张力"。**技术上用户的选择也更优**：wink 是历史验证最有效且最安全的钩子；
> 摘帽/转身/抛接类大动作易崩（道具被画丢或变形）。
>
> ⚠️**收尾只加一个动作单元，别再叠**——模型按内容量铺时长，动作堆多了最先被牺牲的是变身段（整条片的核心卖点）。
