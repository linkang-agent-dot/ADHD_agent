## 一、方案定稿

| | **幻紫魅影**（基础卡） | **鎏金魅影**（高级卡） |
|---|---|---|
| 定位 | 进度反馈，面向大多数玩家 | 大富翁全通奖励，面向深度付费 |
| 人物 | 阿米娜·紫版（深紫长外套 + 金滚边 + 灯泡串） | 阿米娜·金版（鎏金胸衣 + 金手套 + 金长靴） |
| 姿势 | 沿用主稿（扶帽 + 叉腰） | **换姿势**（候选 A 谢幕摘帽 / B 卡牌飞舞） |
| 暴露度 | 主稿原样 | **比主稿更露**（深 V / 露肩 / 腰侧镂空 / 吊袜带外显） |
| 边框 | 银白·冷金细框 + 简化角花 + **紫内衬** | **红框** + 厚金 + 繁复角花 + 灯泡串 + 宝石角石 |
| 背景 | 帐篷内、观众席方向，暖光热闹 | 暗场中央舞台，单束聚光灯 + 飘落金屑 |
| 构图 | 全身（对齐 80 远航之歌） | 半身偏大（对齐 79 绿茵之星） |

**红框的依据**：X3 自身品质色阶 = 绿 < 蓝 < 紫 < 橙红（`Item.col14` / `Reward.col10` 注释「1/2/3/4 对应绿/蓝/紫/橙」）。
紫框 → 红框正好踩玩家已有的品质直觉，比「银框→金框」的分层信号强得多。

## 二、系统事实（决定了边框只能怎么做）

1. **纪念卡系统没有「品质」字段**。`MemorialCard__MemorialCard.tsv` 只有 `DK_卡片小图`(col4) / `DK_卡片大图`(col5) 两个图字段。
2. **`DK_背景框`(col6) 客户端不读**：全表 84 行**全为空**，表注释写「该字段未使用」；客户端 `UIMemorialCardTemplate.cs:53` 只 `SetImageWithDisplayKey(DKImageSmall / DKImageBig)`。
   → **边框必须画进卡面 PNG**，除非让程序补一行读 col6。
3. ⚠️**别跟炫彩卡混**：`CMemory`（Date 目录 / UIMemoryList）才有 Rarity / 7 星 / 品质框 / 整图动化视频，那是约会回忆卡系统，与节日纪念卡是两套。
4. **卡面规格 = 384×523**（近 20 张统一；老卡有 768×1044 二倍图）。

### 5.3 ⚠️数据回归打脸的两处（2026-07-28 查实证后修正）
调研底座＝`..\..\..\产出-数值设计\X3_卡册优化\X3纪念卡现状调研.md`（数仓实证）+ [[reference_x3_deepsea_memorial_card]]。

**★马戏这套链路＝26 情人节的换皮，参数完全一致**（附录A实证）：礼包→门票→开箱→勋章→**兑换 400:1**→卡；里程碑 50/150/300/500/750/1000/1500 次→50/100/200/400/800/1600/3000；随机奖池 500×0.5%＝**2.5/次期望**。所以情人节的实测结果＝马戏的基线预测。

| 实证基线（10 期节日卡） | 数字 |
|---|---|
| 每期兑换人数 | 800~2,200 |
| 每期总量 | 1,300~3,500 张 |
| **人均** | **1.5~1.8 张，70%+ 只兑 1 张** |
| 兑 5+ 张深度用户 | 仅 1%~5% |
| 情人节完整口径 | 拼图直发 1,647 张 + 商店 2,428 张 ＝ 4,075 张 / ~2,600 人 |

- 🔴**99.7% 纪念卡来自免费渠道**，付费兑换+直购仅 0.08%；直售包历史累计仅 $40,910 / 1,040 人 ＝ 总付费 **1.5%**（垫底）。
- 🔴**单价隐含 $15~30/张**，调研结论「参照海妖碎片 $2/片，纪念卡应 **$1~$3/张**」→ **集市 400 勋章必须降，建议 150**。
- 🔴**"免费玩家能到 L6~L7（8张）"是幻想**（我最初的推算）——历史人均 1.57 张。现实目标＝把人均从 1.6 提到 **3~4 张**（L3~L4），这已经是翻倍。

### 5.4 ⚠️马戏与深海的结构性差异（定价不能照抄）
- 深海宝珠＝**免费转盘**产出 → 远航之歌 93.5% 免费兑、$1.3/张 → 那边要**防免费刷**。
- 马戏勋章＝**只从付费开箱产**（奖池期望 2.5/抽 + 里程碑累计 6150 需开 1500 次）；门票的免费来源只有活动豪礼 703 免费档（1/5/10/20/50/100＝**186 张**）+ BP 积分轨零星。
- → **照抄 400 定价，免费玩家整个节日只能拿 1 张**。这跟深海的问题正好相反。

| 玩家 | 能开几箱 | 到手勋章 | 按 400/张 | 按 150/张 |
|---|---|---|---|---|
| 免费 | ~190 | ~625 | 1 张 | 4 张 |
| 中付费 | ~700 | ~2800 | 7 张 | 18 张 |
| 重付费（锚点包买满 $175） | ~1440 | ~6750 | 16 张 | 45 张（被限购 20 卡住） |
