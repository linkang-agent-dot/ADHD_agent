# HTML 交付物完成后自动打开

- 用户偏好：生成 HTML 交付物并完成验证后，自动用本机默认浏览器打开，不再只提供文件链接。
- 边界：只自动打开本次新生成且已验证的 HTML；不自动发布、上传或打开其他外部页面。
- Windows 固定执行顺序：
  1. `Test-Path -LiteralPath <html>` 确认目标是本次生成的单个文件。
  2. `Resolve-Path -LiteralPath <html>` 取得确定的绝对路径。
  3. 用 `Start-Process -FilePath <绝对路径>` 交给 Windows 默认程序直接打开；用户要的是页面本身，不是资源管理器选中文件。
- 路由铁律：本地 HTML 不先交给浏览器自动化导航 `file://`。该控制面可能直接拦截本地 URL，并在拦截后禁止改走间接路径；一开始就走 Windows 默认程序才是正确入口。
- 交付标准：验证通过 → 自动直接打开 → 再给用户文件链接与验证结论。只有用户明确说“不用打开”时才跳过自动打开。
