# Browser 失败必须自行跑完恢复链

## 触发背景
2026-08-03 查询 FCOL 国服官网时，Browser 首次加载到了缺文档的旧缓存版本，`iab` 也不可用。助手过早报告 Browser 不可用，直到用户提醒后才检查出本机存在完整新版本和在线 Chrome 插件。

## 固定恢复链
1. 检查 Browser 插件缓存的所有版本和必需文件，优先最新完整版本。
2. 用完整版本重建运行时，不复用绑定旧版本的坏状态。
3. 读取 troubleshooting，并调用一次浏览器实例发现。
4. `iab` 不可用不等于 Browser 不可用；用户允许或指定 Chrome 时，继续检查 Chrome extension。
5. 以真实目标页的标题、最终 URL、DOM 三项成功作为跑通证据。
6. 上述链路全部失败后才能报告不可用，不能要求用户理解内部加载流程。
