# 过度扩大本地 HTML 自动打开限制

- 日期：2026-08-04
- 任务：交付 BINGO 101830 补偿核对页
- 用户纠正：用户指出此前是直接用默认浏览器打开本地 HTML，并非打开文件夹后再手动双击。
- 现象：把当前浏览器控制面的 `file://` 导航禁令表述成“Codex 不能自动打开本地文件”，结论范围过大。
- 根因：混淆了浏览器自动化 URL policy 与操作系统文件定位/用户手动打开能力。
- 处理：本轮浏览器自动化已明确拒绝 `file://` 并禁止改走间接路径，因此不能在命中该拒绝后再用系统默认程序绕行；此前打开资源管理器并选中文件仍未满足用户的“直接打开”要求。以后交付本地 HTML 时，一开始就选择合规的系统默认程序打开方式，不先进入受限浏览器自动化路线；并明确区分“当前浏览器自动化不可导航”与“Windows 默认程序可以打开”。
