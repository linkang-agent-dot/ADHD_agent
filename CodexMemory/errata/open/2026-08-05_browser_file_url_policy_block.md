# 浏览器控制策略禁止打开本地 file URL

- 日期：2026-08-05
- 任务：真实点击验证《X3 英雄皮肤主动 BUFF 交互 Demo》
- 现象：Browser 成功连接 Chrome，但 `goto(file:///C:/...)` 被 URL 安全策略拒绝，明确禁止通过其他浏览器面或间接方式绕过。
- 根因：浏览器控制能力不允许代理访问本机 `file://` 页面；这不是页面代码错误。
- 处理：立即结束 Browser 会话且不换表面绕过。后续只做静态资源/JavaScript 语法/渲染检查，并把最终单文件用系统默认浏览器打开，由用户直接体验交互。
- 状态：open
