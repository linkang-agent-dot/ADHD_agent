# PowerShell 逐文件 C# 上下文扫描超时

- 日期：2026-08-06
- 任务：巡检 X3 非航海之路的累计权重反向遍历问题
- 现象：对 client/server 全量 `.cs` 逐文件 `Get-Content` 并逐行构造上下文，30 秒内未完成，被工具超时终止。
- 根因：PowerShell 对数千文件逐行解释执行开销过大，没有先用高性能文本索引缩小候选集。
- 处理：改为 `rg` 两阶段筛选：先定位含反向遍历的文件，再在候选文件中核对权重/随机上下文。
- 状态：open；大仓静态扫描默认先 `rg` 限定候选，避免 PowerShell 全仓逐行循环。
