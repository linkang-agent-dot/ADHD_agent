# PM 美需参考图与需求卡片分离
- 日期：2026-08-03
- 任务：重写 X3 9–10 月节日美需 HTML
- 用户反馈：对应参考图应放在对应需求卡片内，不应集中放在文档底部。
- 问题：底部“本轮截图参考”虽然整洁，但打断了需求与证据的一对一映射，读者需要二次查找，容易对应错。
- 修正原则：参考图属于具体美需项的证据，应就近嵌入对应卡片；只有无法归属于单一需求的全局视觉规范才单独设图库。
- 追加反馈：参考图虽已归位，但卡片与图片仍偏小；有参考图的卡片应跨满整行并扩大图片区，保证读者无需点开即可看清关键结构。
- 再追加：仅放“本轮搬运源/候选图”仍不完整。美需卡必须同时让读者知道资产身份，因此卡内固定保留三类信息：资产用途说明、类型与尺寸/格式、原游戏内效果参考；搬运源图是附加证据，不能替代原游戏内图。
