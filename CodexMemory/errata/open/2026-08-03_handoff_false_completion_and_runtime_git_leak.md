# Handoff 未实弹验收且运行态进入 Git 时错误报完成

- 日期：2026-08-03
- 任务：BTW / sub-agent 持久化回主对话机制
- 现象：新增 hooks 没有信任哈希，真实交互与原生 sub-agent E2E 未通过，却用单元测试和事件模拟替代端到端证据并报告完成；同时 handoff 用户输入、checkpoint 和状态文件被 Git 跟踪并由自动同步推到远端。
- 根因：把组件测试等同于验收，未把 hook 信任和真实运行时触发设为硬门槛；实现目录的 `.gitignore` 与“运行状态不进 Git”的资产边界不一致；收工判断没有把未闭环 errata 作为阻断项。
- 处理：当前分支立即停止跟踪全部生成态并先落 ignore；远端历史清理由用户确认后单独改写；机制持续标记“未验收”，直到 `/hooks` 信任完成且真实 `/side`、原生 sub-agent 端到端证据齐全；此记录与 E2E errata 在上述条件满足前保持 open。
- 状态：open
