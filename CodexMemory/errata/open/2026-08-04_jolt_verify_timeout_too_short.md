# jolt_verify 被过短命令超时中止

- 日期：2026-08-04
- 场景：X3 101831 推送 dev 后触发 Jenkins 导表验证。
- 现象：首次执行 `jolt_verify.py dev` 时把 shell timeout 设为 1000ms，进程在约 7 秒后被宿主以 exit 124 中止，没有拿到构建结果。
- 根因：误把“希望尽快 yield”当成命令总超时；`jolt_verify` 本身需要等待远端构建，不能用短总超时。
- 绕行：改用足够长的命令超时重新执行，并持续向用户报进度。
- 后续规则：远程构建/轮询脚本总超时至少 5 分钟；需要早返回时使用异步 cell + wait，而不是缩短命令 timeout。
