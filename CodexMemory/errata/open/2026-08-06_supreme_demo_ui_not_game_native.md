# 至尊 Demo 使用了脱离游戏的网页式 UI

- 日期：2026-08-06
- 任务：X3 至尊皮肤抽奖与晋升交互 Demo
- 现象：虽然底图来自游戏，但抽奖切换卡、晋升面板、按钮和规则区域大量使用自绘 HTML/CSS 样式，整体更像评审网页而不是 X3 游戏内界面；用户指出与游戏 UI 完全脱离。
- 根因：把“真底图挖孔”误解成只需保留截图背景，没有坚持新增控件也必须来自游戏真实 Sprite/现有 prefab；frontend-design 的网页表现压过了 X3 原生组件约束。
- 处理：停止在当前样式上微调。重新反查马戏福箱、英雄主页和通用弹窗的 prefab/Sprite；手机内部只允许真实截图、真实组件或从真实截图精确裁出的槽位，评审说明移到手机外。
- 状态：open，待真组件版 Demo 验收。
