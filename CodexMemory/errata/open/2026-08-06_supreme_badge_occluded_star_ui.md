# 至尊徽记遮挡英雄星级

- 日期：2026-08-06
- 任务：X3 周年限定皮肤至尊升级 UI 效果图
- 现象：生成图把新增至尊徽记放在角色下方中央，遮挡了原有星级展示；用户指出该元素不应占用星级区域，并确认可放到英雄名称左侧。
- 根因：生成提示只要求新增至尊徽记，没有把既有星级区域列为禁止覆盖区，也没有预先规定徽记的合法锚点。
- 处理：补跑局部修正版；删除中央徽记，将缩小后的徽记放到英雄名称左侧。后续 UI 生成中，新增品质标识必须绑定既有标题栏锚点，并明确所有数据、星级和交互热区不可遮挡。
- 状态：resolved。修正版已验收：中央徽记已删除，星级区域恢复；小型徽记位于英雄名称左侧。
