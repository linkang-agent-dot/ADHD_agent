# 本地 HTTP 服务对手写中文文件 URL 返回 404

- 日期：2026-08-05
- 任务：运行英雄主动 BUFF Demo
- 现象：本地服务成功启动，但手工拼出的百分号编码中文文件 URL 返回 404；PowerShell 继续读取空响应导致 Status/Bytes 为 null。
- 根因：直接手写长中文文件名的 URL 编码，未先从服务目录页或 URI API获取真实 href；同时请求失败后仍继续读取响应对象。
- 处理：先请求根目录确认服务与实际 href，再使用返回链接或复制一份 ASCII 入口文件用于本地测试；请求命令在失败时立即退出，不读取空对象。
- 状态：open
