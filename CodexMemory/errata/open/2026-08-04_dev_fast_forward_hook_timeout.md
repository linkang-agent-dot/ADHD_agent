# dev 专用工作树快进被仓库钩子拖到命令超时

- 日期：2026-08-04
- 场景：基于最新 origin/dev 重跑 X3 马戏节总体扫描。
- 现象：`git merge --ff-only origin/dev` 与后续扫描合在一个 120 秒 shell 调用中，命令被宿主以 exit 124 中止且没有实时输出。
- 原因：快进触发仓库钩子/后续处理耗时，且把快进、扫描、status 串在同一命令，无法判断卡在哪一步。
- 绕行：先单独检查 HEAD/status/merge 状态；若尚未快进，拆分执行并给足总超时，再单独跑扫描。
- 后续规则：X3 gdconfig 的 git merge/pull 与扫描不要放同一 shell 调用；仓库操作总超时至少 5 分钟，并在每步后独立取证。
