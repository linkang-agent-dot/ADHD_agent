# Unity 脚本目录宽范围 rg 超时

- 日期：2026-08-06
- 场景：等待玩家登录时定位 `CRankCfg` 生成类。
- 错误：同时递归搜索 `Assets/Scripts` 与 `Assets/Hotfix` 的全部 `.cs`。
- 结果：超过 36 秒后命令超时。
- 原因：Unity 工程脚本树过大，未先根据生成代码目录或文件名缩小范围。
- 正确做法：先用 `rg --files` + 文件名/目录关键词定位 Cfg/ProtoGen 目录，再对候选文件搜索。
- 防复发：大型 Unity 仓库文本搜索采用“文件清单缩圈 → 内容搜索”两步，不直接扫完整脚本树。
