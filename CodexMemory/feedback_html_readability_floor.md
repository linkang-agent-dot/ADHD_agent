# HTML 交付默认可读字号下限

- 日期：2026-08-05
- 来源：用户连续反馈“字太小看不清”“以后出 HTML 时优化”。
- 适用：给用户直接阅读的报告、数据看板、原型说明 HTML。

## 默认门槛

- 页面正文：至少 16px，推荐 17px。
- 承载有效信息的说明、表格、卡片详情：至少 14px。
- 卡片标题与模块标题：至少 16px；关键数字 22px 以上。
- 10–12px 只用于不影响理解的装饰性编号、英文眉题或状态微标签，不能承载结论、口径、投放方式、数据分母。
- 信息太密时优先减少列数、增加折叠和留白，不通过缩小字体解决。
- 移动端继续保持有效文字≥14px，并把多列卡片降成单列。

## 交付前检查

1. 搜索 CSS 和行内样式里的 `font-size: 9px` 到 `13px`。
2. 逐项判断是否承载有效信息；若是，提升至14px以上。
3. 实际打开页面，以100%浏览器缩放检查正文和表格，无需放大即可阅读。
