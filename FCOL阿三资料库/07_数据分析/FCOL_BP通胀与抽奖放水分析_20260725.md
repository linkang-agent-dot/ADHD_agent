# FCOL BP通胀与抽奖放水分析（2026-07-25）

> 口径说明：官方不公布BP投放总量；官网概率公示无聚合列表页（公告列表404、搜索引擎收录残缺），
> 故用三个可复核替代指标：①战力锚点卡价（购买力）②红钥匙发放量（免费抽奖券供给）③抽奖SKU密度时间线。

## 一、购买力尺（战力锚点价格）
| 时间 | 标杆 | 价格 |

| ~2025上半年(时刻早期,阿三口径) | 顶级时刻2-3兆 / 亨利5-6兆 / 大罗~10兆 / 马尔蒂尼几十兆 |

→ "版本毕业"所需BP 一年半涨约两个数量级（时刻大罗10兆→永恒大罗4400兆）。机制=军备竞赛换锚(赛季→WG→时刻→永恒)，非同卡涨价；同代内反而通缩(C罗半年-33%)。

## 二、免费抽奖券供给（红钥匙，阿三07-15测算）
- 2025春节：签到30把起步，"不充值两三个月100把到顶"
- 三次放水节点：2025-04-30排位奖励升级 / **2025-06-19胜利币兑换盒子** / 2025-07-25阵容挑战2.0
- 2026-07现状：核心玩家月产~270把(签20+盒200+排40+杯12)，年获取3100-4000把
- **同比：免费抽奖供给 ≈ 8-10倍**

## 三、抽奖SKU密度（同期对比）
- 2025年6-7月：预售+赛季卡池+胜利币盒子 ≈ 2-3个SKU
- 逐季加码：2025-10扭蛋机常态化 → 2025-12金银战袍体系 → 2026-02起限量500转盘月更
- 2026年6-7月：转盘(吉鲁/苏亚/图拉姆/C罗/罗伊斯)+金靴令+红钥匙+**新金钥匙**+豪门盛宴+金银战袍周更+618连锁+扭蛋机 ≈ **8-10个并行SKU，同比3-4倍**

## 四、结构性收水（放次数、收保底）
1. 5000保底事实上锁：极限玩家一年仅~2700把，"不允许中小R触碰5000保底"（阿三）
2. 新颜色钥匙隔离顶级卡池（金钥匙苏亚雷斯已落地；老红钥匙→中低档池，蓝钥匙剧本重演）
3. 金银战袍BP比例不升+垫子缩水；"欧皇概率暗改""豪门盛宴浮动概率"被博主质疑
4. 2000保底档奖励降级（图拉姆级→罗伊斯级）

## 五、判断与策略
- **名义放水(次数/SKU)同比3-10倍 + 单抽期望同步被砍 = 通胀发钞+暗中换锚**
- BP/钥匙=贬值资产：红钥匙别囤(保底上限已被拿走)、遇到合适保底就花；BP赚了就花
- 保值排序：低薪稀缺顶卡 > 垫子/保护券(供给在缩) > 当期顶卡 > BP现金
- 前瞻：165时代/永恒+2在路上，今天的永恒=明天的时刻；明年同期大概率出新卡种


## 六、抽奖口BP投放定量（官方概率公示实抓，07-25补）
- **2025-12邀请活动概率表**：低档(邀3-5人)=100亿BP@99.445% / 800亿@~0.5% / 1兆BP@0.005% / 珍藏礼盒@0.007% → **单抽期望≈104亿≈0.01兆**；活动标题主打"必得1800亿、抽1兆"=当时1兆是头奖量级
- **2025-10扭蛋机充值搭售**：10元档2亿BP…1000元档8亿——直售BP口子极小，放水走"送抽数+送代币"
- **2026-06胜利币**：8000胜利币=60兆BP/次（纯白嫖产出）
- **预估**：活动BP大奖量级 1兆→60兆(~60倍/半年)；核心玩家活动口年入BP 从<20兆 → 700-1500兆(**30-70倍**)；与卡价百倍级通胀同向吻合，通胀闭环成立
- 购买力换算：年白嫖700-1500兆≈1/4张顶级永恒——官方精确维持"白嫖差一步"距离（红钥匙保底上锁的BP镜像）
- 操作含义：BP计价的囤积=缴通胀税；想买的卡在贬值(C罗腰斩)，"等"优于"攒"


## 七、2026年8-10月放水预测（07-25判断）
判断：**继续放水≈确定**，但为贬值型放水（放钥匙和数字，不放购买力）。依据：
1. 金钥匙体系7月刚落地，冷启动必撒币——阿三已点破官方剧本"大幅发放红钥匙使人手上千把，把2000档名义上移为5000，实际价值不变"→ 8-9月预期红钥匙雨
2. 季节性：去年同期即放水旺季（9月上卡洛斯、10-17扭蛋机上线），Q3-Q4=SKU扩张窗口（暑期+国庆）
3. "全民永恒"排队名单未完（马尔蒂尼/格列兹曼/莱万候选+返场惯例）→ 持续换锚压旧卡价格

持仓含义：BP即赚即花不变；红钥匙遇合适保底就清；4000兆级现有顶卡预期阴跌（C罗腰斩剧本重演）→ **8-10月=旧顶卡买入窗口，勿追新卡首发**。
盯的信号：①金钥匙首个5000保底标的定价=官方新锚 ②若出"永恒+2第二波/165时代"→换锚加速、窗口更肥。
