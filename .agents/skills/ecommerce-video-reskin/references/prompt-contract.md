# Prompt与参考包契约

## 参考材料角色

每个生成任务先声明参考角色，禁止让两份参考互相抢控制权：

- `source_video`：人物、表演、动作、机位、光线、场景、运镜、节奏、真实剪辑点和时长。
- `product_reference`：商品颜色、肩带、杯面、边缘、下围、包装或其他结构事实。
- `scene_keyframe`：商品在目标场景、人物手持或目标穿着状态下必须长成的样子。
- `state_keyframe`：最大拉伸、开合终态、无痕结果等关键状态。

每张参考图只表达一个主体、一个视角、一个状态。正背面、拉伸前后、多个商品不得拼图投喂。

## Prompt顺序

按以下顺序写，不写散文：

1. 任务：严格复刻参考视频，只替换什么。
2. 保留项：人物、场景、动作、机位、运镜、节奏和剪辑点。
3. 替换项：商品结构、颜色、目标痛点或目标状态。
4. 最小动作：这一段唯一必须发生的动作。
5. 固定项：商品不可漂移的结构和状态。
6. 禁止项：旧商品残留、增删肩带、Logo、文字、手指粘连、额外切镜等。
7. 输出：时长、比例、无字幕/无Logo/是否静音。

## 通用模板

```text
严格复刻参考视频的场景、人物、表演、动作顺序、机位、运镜、光线、节奏、时长和原有剪辑点。

唯一替换：把画面中的【旧商品】替换为参考图定义的【目标商品】。商品必须保持【颜色、结构锚点】。

本段唯一动作：【最小动作】。场景关键帧只负责锁定【关键状态】，其余动作与节奏仍以参考视频为准。

全程禁止：残留旧商品；改变商品款式；增删肩带/缝线/下围；生成品牌、Logo、字幕或价格；手指穿透商品；新增原片不存在的切镜、转身或运镜。

输出【时长】【比例】视频；画面无字幕、无Logo；声音按后期方案处理。
```

## 失败后的修改顺序

1. 商品读错：先修场景关键帧，不继续堆商品形容词。
2. 动作或剪辑错：缩短精确参考视频，删除Prompt里原片没有的动作/切点。
3. 接触错：补接触关键帧或拆成两个镜头。
4. 状态切换错：分别锚定两个状态，后期硬切。
5. 主体已正确但画面太静：追加PC，不让模型重新生成大动作。
