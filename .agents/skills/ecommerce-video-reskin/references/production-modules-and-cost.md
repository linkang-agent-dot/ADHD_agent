## 制作模块

| 模块 | 输入 | 输出 | 通常是否付费 |
|---|---|---|---|
| 素材输入 | 本地原片、商品图 | 可复核源文件 | 否 |
| 原片理解 | 全片画面、声音、字幕 | 产品、痛点、剧情、解法、核心逻辑、亮点 | 否 |
| 骨皮设计 | 原片模块、目标商品 | `reuse/reskin/rebuild` 清单 | 否 |
| 商品参考 | 正背面、结构、颜色 | 单主体单状态参考 | 可能 |
| 场景关键帧 | 原片风险帧、商品真源 | 可直接作为视频锚点的静态帧 | 是 |
| 分段视频生成 | 参考视频、关键帧、Prompt | 独立无字/静音候选 | 是，主要成本 |
| 本地拼接 | 已通过模块 | 统一规格成片 | 否 |
| 声音 | 原声/TTS/环境底轨 | 连续正式音轨 | TTS可能付费 |
| 特效字与修补 | 文案、时间轴 | 本地包装 | 否 |
| QC | 成片、抽帧、ASR | 验收报告 | 否 |

## 成本分类

- `production`：为了交付当前成片实际发生的所有付费调用，包括判退重跑。
- `r_and_d`：模型对比、接口探索、非当前方案实验。
- `historical_reuse`：历史生成资产本轮复用；本轮新增成本为0，但从零报价不能忽略。
- `local`：剪辑、抽帧、转码、ASR、字效和QC，本机模型积分为0；人工时间另算。

任何总结至少同时报告：

1. 本轮新增生产积分。
2. 从零复制同规格的估算积分。
3. 研发试错积分。
4. 人工介入时间或计算公式。

## 模型选择

| 情况 | 默认路线 |
|---|---|
| 简单商品举稳、单状态、微动 | Mini + 合格场景关键帧 |
| 人物/动作/机位必须严格复刻 | 2.5 |
| 手指接触、遮挡、拉伸 | MK；复杂时拆镜或2.5 |
| 商品正确但画面太静 | 本地 PC |
| 精确A/B状态 | 两张已验收状态图分别生成或直接硬切 |
| 无痕穿着结果 | SS + PC，不做自由转身 |

普通2.0/VIP能改善剪辑结构，但不能默认替代2.5完成真人原片精确换皮。Mini不能单条承担复杂A/B切换。

## 报价方法

稳定Mini量产估算：

```text
商品/场景关键帧 20～40点
+ 需要换皮的模块数 × 54～60点
+ 预留返工次数 × 54～60点
= 预计生产积分
```

正式混合版把复杂模块的Mini成本替换为2.5成本。人工成本单独计算：

```text
综合成本 = 积分成本 + 人工小时 × 内部小时单价
```

不要把已有历史模块按0元当作下一条“从零生产”的承诺。
