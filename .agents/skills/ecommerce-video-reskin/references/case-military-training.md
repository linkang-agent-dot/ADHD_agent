# 军训无痕内衣实证

## 需求校正

- 拆解场景：军训。
- 目标商品：粉底肤少女无痕内衣，不是防晒衣，也不是原片深蓝运动内衣。
- 内容骨架：军训痛点开场 → 商品揭晓 → 动作验证 → 结构讲解 → 冰丝透气/弹力 → 白T正背结果 → CTA。

## 关键决策

- 商品未露出的痛点开场直接复用。
- 商品揭晓先用白底商品图失败：模型把细肩带款生成成无肩带抹胸。改为先出场景内双细肩带关键帧，再用原片视频+关键帧重跑后通过。
- 白T无痕正背面分别走静态锚点和微动，不让人物自由转身。
- 原片没有A/B切点，不能在Prompt里硬塞切换；需要对比时分别生成状态后硬切。
- 插入长静态背面证据导致观感突兀，最终删除该静止段。
- 完整原声连续保留；新增卖点用原片风格特效字表达，避免嘴形和TTS冲突。
- 结尾复读通过尾段ASR发现，用同片确认无对白的环境底轨替换第二遍。

## 模型实证

- Mini适合简单商品展示和单状态动作，但不适合单条完成精确服装A/B切换。
- 2.0 VIP能形成硬切，但真人和商品表达仍不稳定。
- 2.5对人物、机位和动作复刻最好，是复杂真人精确换皮的正式选择。
- 已批准主体仅缺节奏时，用PC比重新生成更稳。

## 成本实证

- 商品揭晓：124点，包括失败视频54点、关键帧候选16点、锁款重跑54点。
- 跑跳无痕段：本轮两次Mini共120点。
- 冰丝透气段：约54～60点。
- 当前最终链新增约298～304点；其他段复用历史资产。
- 该数字不是从零复制成本，也不包含早期模型/API/TTS研发试错。
