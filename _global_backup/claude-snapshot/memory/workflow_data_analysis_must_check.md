## 一、先建框架（沟通阶段第一件事,别急着查数）
**回归=模块装配。模块=一个设计动作,它回答"这个动作有没有达到目的";目的决定靶指标,靶倒推口径。第一步永远是列"这个活动做了哪些设计动作"→ 模块清单=报告目录,和用户对齐后再动手。** 建框架靠:问策划 / 查 ActvOnline 配置 / 看排期甘特 / 看往期同节日。
配套开工三问:
1. **先问设计方案再查数据**:每个动作的目的/预期是什么?"设计了但没人买"是关键发现;没有预期就先反推一个再算 gap。
2. **本案有「口径统一.md」吗?** 有→先读禁自创;没有→开工就建(服段/窗口/分母/iap 四段起步)。
3. **给活动下判词**:这是拉宽(付费率/渗透)还是拉深(ARPPU/客单)的活动?后面结论围绕它展开。

## 二、逐模块认靶+套规则卡,禁承袭上一个模块（用户核心痛点）
**框架里每个模块,去 [[reference-data-analysis-module-registry]](模块库)翻卡:先认它的靶指标(效果体现在哪,如排行榜→头部付费/阶段奖励→节点转化),再按靶倒推的口径走。禁复用上个模块的范围。** 库里没有=现建卡(先想清目的和靶)。口径由靶决定,通用四问兜底:
- ① 窗口 = 该模块**自身活动窗口**(≠节日全窗;深海周卡晚开6天用全窗付费率被低估 3.6%→5.1%)
- ② 服段/人群 = **靶要求的那群人**(排行榜→头部;掉落→参与者)+该模块实际部署段(跨期对比同段/同生命周期;服数不同只比率不比绝对值)
- ③ 分母 = **该窗×该段总付费人数**(或靶要求的分母,如条件漏斗=到达阈值付费玩家),写进表注
- ④ 对照 = **形式同构先例** + **自然衰减基线**(功劳是逆转衰减不是绝对增长)
每模块收尾回答一句:**它有没有达到目的?**(靶动了=达到/没动=没达到/靶动别的没动=定向生效)

## 三、指标铁律（最易违反）
- **三件套缺一不可**:收入/买家/**付费率**/ARPU/ARPPU/复购/max,逐档带。
- **优先付费玩家ARPU**(=模块流水/全部付费玩家,最准);ARPPU会骗人(掩盖买家塌);付费率跨期不可比。
- ARPU 分母=当日总付费人数;判趋势/衰减回升用 /DAU 口径(别用/付费人数)。
- 付费率用付费玩家基底不用活跃;转化率漏斗分母=到达阈值的窗口付费玩家。
- 免费投放报人均不报总名义;事件型先归一化到单事件再判走势。
- 模块按名字语义归类不靠id段;大R集中服排除;n<15标波动。
- **判"活动有没有在某服跑"用参与口径,禁用订单口径**(ods_user_asset 的 reason_id / ods_user_activity);活动配置ID在 `ods_user_activity.attribute1` JSON 的 `activityCfgID`(activity_id 列是实例哈希)。
- **圈活动收入必须先圈全该活动的全部付费件家族**:去 Pack 表按活动名反查所有 PackType(链式/成就/储蓄罐/锚点/BP…)+开放式全量 iap 扫描(拉该服窗口内全部售出 iap 肉眼扫,配阳性对照服)互验,**禁只按一张表(如 AchievePack)推**——2026-07-30 航海案连翻三车:只看成就礼包→漏了链条包 207x 家族,把"老版有变现$65/服"误判成"零变现"。多服合查有 100 行截断坑,必须分服查。
- **圈族禁用裸 ID 前缀,必须落到名单+抽查名字**:同前缀≠同功能(2026-07-30 海妖案:2014001-005=海妖转盘、2014006-012=联盟IPO 混排同前缀,substr 圈法把 IPO $2.1k/日 混进海妖线,+29% 被吹成 +95%);substr 只许探路,出结论前换成 grep 名字得到的具体 ID 名单。
- **Datain 同名指标先辨 cohort**:指标库同名指标常有 cohort 版和大盘版(如「付费用户数」),`cohort:true` 带 `_0d` 后缀=当日新注册用户的表现,**查大盘禁用**;大盘付费人数用「去重付费用户数/平均付费用户数[日]」;交付前必算 ARPPU 合理性(SLG 大盘 $10~30 量级,$200+ 即口径错)——2026-08-03 Codex 实弹翻车立规,护栏同步已写进 datain-skill SKILL.md。
- **X3 订单收入一律 sum(pay_price)**:`ods_user_order.actual_charge` 是**本地货币**(RUB/TOKEN=USD×100等,pay_channel 80 卢布单笔能虚成7800),用它汇总会把收入虚增几倍、造出假巨鲸;pay_price=美元标价,才是跨币种可加口径(2026-07-27 圣甲虫返场商店案:actual_charge口径$40.5k vs 真实$13.6k)。

## 四、结论呈现铁律
- **每条结论 = 一句话判词 + 数据锚点 + 配图,成对出现、先结论后图**;禁纯文字长段、禁裸图无结论、禁"定位/本质上"无数据抽象话("对打"→"历史数据对比")。
- **三段式**:🤖数据层 → 👤判断层(一句大白话) → 🔧建议;判词配色标[正常绿/关注橙/异常红]。
- 逐模块章=大结论(黄框)+胶囊切换+小结论(蓝框);单模块页必备设计回溯思维导图(礼包/流程/数值三支)。
- 增长结论点名主要增长因子(增长=ARPPU×付费率×盘子,明说哪个在动);盲区单列"待人工补充"。
- 给+2只留四类:总额/涨幅%/ARPU/占比;HTML本地打开不发Artifact,归档KB。
