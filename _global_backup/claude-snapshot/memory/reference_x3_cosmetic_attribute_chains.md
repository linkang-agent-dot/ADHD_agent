## ① 英雄皮肤：皮肤无等级，属性是固定值
`Hero__HeroSkin.tsv` 列(0-indexed)：[0]ID [2]Name [3]Group(hero id) [10]**Regained**(重复获取转钻补偿"单日|累计",**与属性无关**别误读) [11]ObtainItemID [12]**PropType** [13]**PropNum**(兵种加成,万分比) [14]**Power**(战力) [15]SkillList [16]buff备注(属性名) [20]DK_Video。
- 皮肤属性 = `兵种攻击 +PropNum/100% · 战力Power`，**固定值·皮肤没有等级/升级表**。
- 本体技能(HeroSkill) ≠ 皮肤属性，是两个字段：本体随**英雄等级**成长(L1→L100,显示满级值)；hero_id=1000+Role_C_n;HeroSkin id=(1000+n)*100+skinNum。
- ❌曾错把 PropNum(col13)+Power(col14) 当成 min→max 范围 → 显示成假范围"+30%→+360%"，已修。

## ★英雄皮肤「品质档」在哪里定（2026-07-28 实证，找错过两轮）

用户说「这个皮肤应该是传说，现在是史诗」时，**不要去 Hero__HeroSkin.tsv 找 Quality 列——没有这个字段**（全表 22 列查过）。
也不在 `Skin__Skin.tsv`（那张表有 Quality，但装的是主城/头像框那套皮肤系统，英雄皮肤不在里面），
更不在 `Reward__Reward.tsv` 的 `GoodsQuality`（全表仅 262 行有值，皮肤道具全为空）。

**英雄皮肤的品质＝两个 DK 字段表达出来的，没有数值字段**：

| HeroSkin 列 | 含义 | 取值 → 档位 |
|---|---|---|
| col19 `DK_SkinListFrame` | 卡片边框 | `..._bg3`＝素金细边（**史诗档**）／`..._bg2`＝带蓝玫瑰角饰华丽金框（**传说及以上**） |
| col17 `DK_CollectIcon` + col18 `CollectTxt` | 典藏图标 + 标签 | title2=传说 / title3=史诗 / title4=限定 / title5=至尊 / title1=周年 / title6=夏日 / title7=黑金 |

**关键理解：边框＝品质档，标签＝品类，两者独立。** 库里 `bg2` 与 title1/2/5/6/7 多种标签都搭过；
所以「限定标签 + 传说边框」是合法组合，改品质**只动 col19，不用动标签**。
判档位的可靠方法＝按 (col19, col17) 组合分组统计，看哪些皮肤落在同一组（bg3+title3 那 5 个就是公认的史诗皮肤）。

**另一处别搞混：道具品质框** `Item.col23 DK_Background`＝`DK_Bg_CM_Item0..5`，实测颜色：
0棕 / 1绿 / 2蓝 / **3紫＝史诗** / **4金橙＝传说** / 5幻彩＝至尊。
⚠️ 直觉上「Item4」像是第四档紫色，其实 Item4 已经是金橙传说框；所有英雄皮肤道具本来就用 Item4，**这里通常不需要改**。
