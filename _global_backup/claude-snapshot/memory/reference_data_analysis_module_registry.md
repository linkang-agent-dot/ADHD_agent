# 数据分析模块库（设计动作 → 效果验证 映射手册）

> **核心认知(用户2026-07-22逐层定):**
> 1. 回归不是有固定章节的策划案,是"很多模块拼出来的",不同活动模块组合不同。
> 2. **模块 = 一个设计动作(加进去的东西);它在回归里回答的是"这个动作有没有达到它的目的"。**
> 3. **一个动作的目的,决定了它的效果该用哪个指标来验证(靶)。** 加排行榜→看头部付费;加阶段奖励→看节点转化。
> 4. ★所以**口径/范围是被"要验证的效果"倒推出来的,不是自选的**——这才是"范围瞎搞"的根治:问题决定口径。
>
> 分析流程=①建框架(列这次活动做了哪些设计动作=模块清单)→②逐个来本库查卡→③按卡的靶+口径验证。通用认知/框架装配/呈现见 [[reference-data-analysis-playbook]];案子专属服段/窗口/iap 进各案「口径统一.md」。
> **进化规则**:遇到库里没有的动作→新增卡;某卡的靶/口径被实战修正→改对应卡,别散写。

---

## 卡片的纲（每张卡四格）
| 格 | 含义 |
|---|---|
| **验证/意图** | 加这个动作是为了解决什么、拉动什么(它的目的) |
| **靶指标** | 有效的话效果该体现在**哪个指标/哪群人**上(度量对准这里,别看错地方) |
| **度量口径** | 为了看这个靶,用什么窗口/分母/分析框架(口径由靶倒推) |
| **踩坑** | 该动作特有的坑 |
> 通用三件套(付费率/ARPU/ARPPU)、R级分层、三段式结论所有模块都要,不在卡里重复。**每个模块必回答一句:"它有没有达到目的?"——靶指标动了=达到,没动=没达到,靶动了但别的没动=定向生效。**

## ★示范（用户给的两个范例,吃透纲再往下看）

### 排行榜
- **验证/意图**:加榜是为了**刺激头部玩家为排名竞争而多付费**(不是拉新、不是拉广度)
- **靶指标**:**顶端玩家(超R/大R)的付费额/ARPPU**;榜内 vs 榜外玩家付费对比;冲榜临界名次附近的付费跃升。⚠️别用"整体付费率"当靶——那不是榜的目的,会得出"没效果"的错判
- **度量口径**:窗口=榜开放期;人群=超R/大R分层 + 榜 TopN;看这批人 ARPPU 环比/对比无榜期
- **踩坑**:头部集中→小样本鲸鱼敏感,单个大R能改变数据,需多服验证;榜奖若外显向要结合外显拥有率看

### 阶段奖励 / 进度节点奖励
- **验证/意图**:加阶段奖励是为了**推玩家跨过进度节点、往深处走**
- **靶指标**:**各节点的到达→通过转化率有没有提高**;玩家停留深度是否前移;进度墙位置是否松动
- **度量口径**:窗口=活动期;框架=节点漏斗(到达该节点人数→通过人数),对比无阶段奖励时/上期同位置;全量 vs 付费玩家两条曲线(付费玩家也卡=奖励诱因不够,非资源不够)
- **踩坑**:门槛校准是隐形杀手(奖励不够诱人则推不过节点);跳档+免费墙处会断崖

> 看懂没:同样是"加了个东西",排行榜的靶在**人群维度(头部)**,阶段奖励的靶在**流程维度(节点转化)**。靶选错=分析对错地方=结论作废。下面每张卡都先认靶。

## A. 整体层（串起所有模块,回答"整个活动净拉动了多少")

### 节日总体
- **验证/意图**:这个节日整体把基本盘拉动了没有(而非各模块自评)
- **靶指标**:总营收 / 节日占比 / **付费玩家ARPU 净增**(对照自然衰减基线);单服收益(重上优先级)
- **度量口径**:窗口=完整节日周期对标同长上期;分母=全部付费玩家;框架=新增量归因(新老服baseline,共有模块看蚕食/新模块算纯增量)
- **踩坑**:替代vs叠加(净增≠礼包直接收入,查存量非节日消费有没被挪账);服数不同只比率不比绝对值

## B. 礼包类

### 连锁 / 阶梯 / 链式礼包
- **验证/意图**:阶梯式一层层往深挖付费
- **靶指标**:**档间留存率**(找主断崖档位);爬到高价档还剩多少人
- **度量口径**:窗口=各自活动窗口;分母=该窗该段总付费;框架=按档算留存,阶梯断档对标同价同构链
- **踩坑**:每日刷新与链式推进冲突;flat同价链天生小核心,递进价格阶梯($2.99→19.99)优于flat

### GACHA / 随机礼包
- **验证/意图**:用随机性驱动超额复购
- **靶指标**:**复购次数**(人均消费÷面值,常达1.5-2×)
- **度量口径**:窗口=活动窗口;分母=买家
- **踩坑**:名字常复用旧节日,按语义归类

### 固定 / 低价礼包（$4.99入口款）
- **验证/意图**:破冰引流、把更多人拉进付费池(拉广度)
- **靶指标**:**买家数/付费率**(广度),不是ARPPU
- **度量口径**:窗口=活动窗口
- **踩坑**:固定内容限制复购;若是锚点礼包→它是**价格锚不是销售品**,靶=有没有抬高主力包购买率,不是锚点自身转化

### 进度 / 成就礼包
- **验证/意图**:按进度解锁,越深买越多
- **靶指标**:**逐档触达购买率**(到达该阈值者里买的比例),U型曲线看病灶位置
- **度量口径**:窗口=各自活动窗口;分母=**到达该阈值的窗口付费玩家**;框架=SKU漏斗(解锁×到达×购买)
- **踩坑**:免费墙腰斩到达付费玩家;买全终奖领取BUG先排除再下结论

## C. 养成投放类

### 大富翁
- **验证/意图**:靠骰子驱动的进度玩法拉深参与和付费
- **靶指标**:**圈数深度分布 + 触达购买率**;骰子来源渠道覆盖率
- **度量口径**:窗口=自身窗口;分母=到达某圈人数;框架=全量vs付费玩家两条圈数停留曲线
- **踩坑**:付费玩家也卡某圈=深度驱动力问题(非免费资源不够);组队/前置门槛让产出链归零(小非R组队完成率1.2%)

### BP / 通行证
- **验证/意图**:用赛季进度+付费解锁拉付费深度
- **靶指标**:**满级率 + "满级后购买"转化**;购买率(BP参与者中)/P1→P2升档率;**免费满级玩家=最精准未转化池**
- **度量口径**:窗口=BP各自活动窗口(⚠️不同BP用各自窗口,别把世界杯卡进深海14天);分母=BP参与人数/窗口×服段总付费;满级=activity_step 0-20取20
- **踩坑**:多BP共存iap复用/漂移,归属用窗口commit配置核对别信HEAD;等级靠道具量×暴击期望反推有偏差,有后台字段优先

### 累充
- **验证/意图**:充值达档送料,刺激冲高
- **靶指标**:**各道具投放占比 + 消耗率趋势**(超投会积压)
- **度量口径**:窗口=活动窗口
- **踩坑**:超投橙碎片→积压→碎片类礼包需求塌方;隔离机制;插档安全

### 储值 / 定存(OAP)
- **验证/意图**:先存后取的长线绑定,拉长付费周期
- **靶指标**:**储值期拉升倍数 + 储值后是否跌破基线(透支效应)**;各档ROI
- **度量口径**:窗口=**比活动期长**(追参与者26天);分母=各档参与人数;框架=储值前/期/后三段+R级×档位热力图+人均储值档位数
- **踩坑**:头部依赖易超健康区间(50-70%)

## D. 参与产出类

### 掉落 / 任务
- **验证/意图**:靠战斗/任务发资源,拉参与、导流到付费
- **靶指标**:**参与率(入口) + 完成深度(留存)**两个靶,根因不同(入口隐蔽vs门槛陡增);引流包CVR
- **度量口径**:窗口=参与者·活动期活跃;分母=活跃/PVE战斗次数;框架=**双漏斗**+人均产出P25/P50/P75分位+PVE/GVE分开
- **踩坑**:历史基准取全量服(35+)中位值;窗口未跑满的服(3-6天)排除;reason_id/sub_id拆渠道

### 强消耗积分
- **验证/意图**:设高消耗坑深,榨付费玩家深度
- **靶指标**:**坑深任务达成率**(实际max vs设计目标);付费道具积分占比;付费率相对全服的**倍数**
- **度量口径**:窗口=参与者·分DAU大服/小服两组;分母=全服活跃
- **踩坑**:大服参与率极低(0.2-0.6%分母大)标"仅参考";积分用LAG窗口算增量

### 集卡 / 收集
- **验证/意图**:集齐驱动持续参与+付费补齐
- **靶指标**:**各星级人均集齐率(饱和度)** + 接触率(第一障碍常是没碰到)
- **度量口径**:窗口=本期(**必加create_time≥活动开始**);分母=有过≥1张该星级卡的玩家;框架=有效包vs无效包区分+星级×R级饱和度矩阵(红≥20pp/橙10-20/绿反超)
- **踩坑**:不加create_time→历史积累高估收集度;近半是无效包不产出目标卡;"全参与全完成"假设系统高估30-50pp,引参与率折损系数;session/埋点vs数仓打架以数仓为准(锁game_cd/时间/表名)

### 送礼 / 社交道具
- **验证/意图**:社交赠礼带动情感消费+互动
- **靶指标**:**各来源产出 + 蒸发率(送出vs收到) + 鲸鱼vs平民产出差**;五维评分卡
- **度量口径**:窗口=活动窗口;分母=触及人数;框架=reason_id拆产出来源+消耗时间分布(末日囤积=坏节奏)
- **踩坑**:付费壁垒削弱社交(低触达先怀疑入口);窄覆盖高客单是合法成功模式,别用广覆盖尺子量

### 挖矿小游戏
- **验证/意图**:关卡循环推进拉参与深度
- **靶指标**:**各关卡步转率**(<60%红=问题节点)
- **度量口径**:窗口=循环期;分母=分R级;框架=分R级关卡漏斗(`mining_funnel_template.html`改CONFIG)
- **踩坑**:多节点顺序推进类通用(BINGO/大富翁阶段也套)

## E. 消耗回收类

### 兑换商店
- **验证/意图**:回收活动货币、承接产出
- **靶指标**:**消耗率(消耗÷发放) + 参与转化率(兑换÷获币)**;各商品个人饱和度
- **度量口径**:窗口=活动窗口;分母=获币人数
- **踩坑**:低价高参与商品=消耗性入口锚点;回收率是活动健康度信号

### 推币机 / 转盘
- **验证/意图**:低门槛博彩式拉广度参与
- **靶指标**:推币机=**付费率**(常全场第一,宽口浅底,ARPPU垫底正常);转盘=看格子中奖分布
- **度量口径**:窗口=活动窗口
- **踩坑**:HUD显隐=服务器真开;转盘加奖只能换格;转盘中奖到账客诉另有核查口径

## F. 事件驱动类

### 竞猜 / 场次驱动
- **验证/意图**:跟赛事场次押注,持续拉付费
- **靶指标**:**单场收入(vs首轮基线倍数) + 单买家单场产出**(押场次逐轮腰斩是结构必然,别当衰减)
- **度量口径**:窗口=**单场归一化**;框架=归一化到单事件再判走势
- **踩坑**:按日均/按轮总额看必然"衰减"是假象,两口径冲突以归一化为准

## 外显类通用（皮肤/头像框/纪念卡/家具等,回答"外显向动作有没有效果")
- **验证/意图**:外显(皮肤/框/卡)驱动身份/收藏付费
- **靶指标**:**拥有率/购买转化 + 复购(纯外显复购常倒数)**;服龄拐点(进度不足=外显价值感未到,如皮肤D21偏早D45+回升)
- **度量口径**:资产查 ods_user_asset(Item_前缀);服龄用originSeaArea量化进度
- **踩坑**:老服首轮买家数不能预估新服/重上(人群独立无饱和传导);纯外显复购弱是常态,靠新款而非复购
