## ★★月规划核心方法论（2026-07-29/30 用户重构思路后定，以后所有月规划照此）
> 用户原话："月规划核心要想的是**每个月做什么模块**、什么模块对当前收入最重要→最重要的堆前两个月；后四个月先跑明白 **3 个月周期的付费稳定性**。以**付费占比 40-50%** 为目标往下拆。"
- **🔑核心公式（页面已用实测双向校验）**：`节日占比 = 节日渗透 × 节日ARPPU ÷ 大盘ARPU`
  - X3 07-13 周实测：198人 × $51.8 ÷ $48,599 = **21.1%** ✓（＝直接算 $10,250/$48,599）｜同周 P2：2,500 × $74.2 ÷ $453,284 = **40.9%** ✓
  - → **21%→40% 需要「渗透 ×1.6」×「ARPPU ×1.35」= ×2.16**，正好拆成两个月各攻一个因子。
- **KPI 分月（用户两次纠正后定稿）**：**9 月＝当周该模块收入/当周大盘收入（周占比·攻广度）**；**10 月＝当周节日付费 ARPPU（攻深度）**，且渗透不许掉。⚠️用户明确**否掉了"付费玩家ARPU"口径**（"不走ARPU就看付费在当周的占比就足够"）；分母一律**当周大盘**不是当周节日收入（这样各模块周占比可直接加总对齐 40-50% 目标）。
- **★达标线（P2 同口径逐周实查 2025-10~2026-07，全服）**：
  | 指标 | P2 | X3 现状(成熟服) |
  |---|---|---|
  | 挖孔 单周占大盘 | 16个投放周 **中位15.9% / 峰值42.7%**(05-25拓荒W3) | 无 |
  | 弹珠 单周占大盘 | 12个投放周 **中位9.7% / 峰值26.9%** | 无 |
  | 最强单模块周占比 | 挖孔42.7% | **夏日开箱15.2%**(已达P2挖孔中位线) |
  | 全模块合计周占比 | 常年40-58%(最低19.4%) | **峰值21.5%**(四模块叠出来) |
  | 当周节日ARPPU | **中位$68.9 / 峰值$135.6** | **中位$40.2 / 最高$51.8** |
  | 节日渗透 | 中位51%·主力周60%+ | 中位32%·峰值52.4% |
  - **判据＝主力模块单周占比 ≥15% 算达标、峰值周应 ≥25%**。挖孔累计 $141.7万 vs 弹珠 $74.6万 = **1.9:1**。
- 🔴**三条最硬的结论**：①**X3 单模块强度不弱**(夏日开箱15.2%≈P2挖孔中位)，差的是**一周只一个模块在打、一个月只一两周有** ②**真窟窿是空窗**——X3 有 3 个整周节日占比掉到 **0.3-0.6%**（6/08、6/15、7/27），大盘照常 $45-53k，**补空窗零开发成本** ③**X3 广度与深度互相拖**：渗透最高周(52.4%)ARPPU仅$35.9、ARPPU最高周($51.8)渗透仅31.5%，P2 则两者同时高。
