## 规则1：锚点礼包是价格锚，不是目标销售品

锚点礼包的设计目的是**对比参照**（价格锚定效应），让成就礼包等主力礼包显得更划算。锚点本身购买率低是正常的，不需要"优化锚点购买率"。

**Why:** 作者review时指出"锚点本身设计就是对比，不影响"。把锚点低购买率当问题来分析，暴露了对礼包设计意图的误判。

**How to apply:** 分析锚点数据时，重点看它是否有效抬高了成就礼包的购买率/ARPPU，而不是锚点本身的转化率。

## 规则2：探究关卡/进度节点的转化断崖，应该用全量+付费玩家的停留曲线

不能仅靠"免费资源投放量刚好覆盖到N圈"就断言"N圈断崖是因为免费资源用完"。因为付费玩家会在免费资源基础上额外购买骰子，他们的进度应该远超免费上限。如果付费玩家也卡在同一个节点，那问题就不在免费投放量，而在进度驱动力。

**Why:** 作者指出"如果玩家有付费，他会额外在免费投放后付费，所以170→30圈这点讲不通"。正确做法是拿全量玩家和付费玩家两组的停留关卡曲线对比，看各自在哪里掉。

**How to apply:** 
- 遇到"某个圈数/阶段之后全部0购买"的现象时，不要直接归因于免费资源上限
- 应该查 **全量玩家进度分布** 和 **付费玩家进度分布** 两条曲线
- 如果付费玩家也大量停留在该节点 → 问题在深度驱动力/奖励吸引力
- 如果付费玩家突破但非付费没突破 → 问题才是免费资源不够
- 需要活动参与/进度埋点数据（如 ods_user_activity 或 counter 数据）

---

**延伸：SKU 漏斗法（2026-07-21 大富翁成就礼包首用，任何按进度解锁的礼包通用）**：解锁条件（config：AchievePack/阶段奖的阈值列）× 到达人数（行为 survival 在阈值处取值，必要时做单位换算并标注估算口径，如圈数=掷骰次数÷[棋盘格数÷骰均3.5]）× 按包 id 的购买人数 → 每档**实际购买率，分母=到达该阈值的窗口付费玩家**（用户同日定：转化率类指标一律付费玩家基底，混免费玩家读数无意义，见 [[feedback_module_metrics_payrate]]）。它能把"深档没人买"拆成可行动的问题：大富翁答案=U 型曲线（墙前 11%→3% 正常价格递减=货架弹性、跳档+免费墙同点断崖 1%、墙后回升 9-30%=缺供给非缺意愿），并顺带发现免费墙把到达付费玩家从 1,356 腰斩到 642=续骰位现成客群。实现=`_monopoly_design.py` ⑥ 段。

## 规则6：跨游戏先例对照必须先核"形式同构"，不挑最亮眼的（2026-07-20 大富翁参照被打回教训）

给 X3 模块找 P2 对照时，拿了数据最漂亮的春节异族大富翁（$250k/max$5.8k/随机轨）当"上限参照"，被用户打回：异族大富翁是春节特有形式，与 X3 大富翁不同构。换成同形式的「节日大富翁」族（情人/科技/拓荒三节）后结论完全反转（P2 同形式也是浅盘 max $550-780，X3 单人深度不落后——差的是分层货架不是深度）。
**Why:** P2 同一玩法题材常有多变体（异族=春节特有 / 战装=常驻 / 节日大富翁=通用节日形式），变体间付费结构差一个量级；挑错参照会推出方向性错误的改造建议。
**How to apply:** 选对照前先列该玩法在 P2 的全部变体+活跃窗口（dim_iap 名字 LIKE + 按月分布一查便知），确认玩法机制同构再对比；最亮眼的先例往往是特殊形式，先问"它为什么亮眼"。同名包还要防历史复用名（如"2025复活节大富翁礼包"实际在科技/拓荒窗在售）。

## 规则5：事件型模块（赛事/轮次驱动）的走势必须用"单事件口径"（2026-07-17 竞猜W6误判教训）

淘汰赛类活动可押场次逐轮腰斩（16→8→4→2），按日均/按轮总额看必然"衰减"——这是结构必然不是效果衰减。世界杯竞猜按日均判"奖励升级无效"，换算单场后单场收入=首轮基线1.3-1.9×、单买家单场产出$2.1→$10.1持续走高，结论完全反转（用户改判"还是可以"）。
**How to apply:** 凡供给量随时间结构性变化的模块（场次/SKU数/开放天数），走势先归一化到单事件/单SKU/单日再下判断；两个口径结论冲突时，以归一化口径为准并注明。

## 规则4：逐模块回归页的呈现规范 = 大结论 + 胶囊选择框 + 单视图小结论（2026-07-16 用户定，通用）

逐模块深挖的报告章节，禁止把所有图表/表格纵向堆满（"信息太多人都麻了"）。定式：
- **章级大结论**一条（黄边大字框，模块整体判词，通常是用户拍板的定性）；
- **胶囊选择框**一排切换视图（对打表/分布图/分位数/专项…），一次只显示一个视图；
- **每个视图配一条小结论**（蓝边大字，跟着选中的视图走，先结论后图）；口径注释收进视图内小字。

**Why:** 双节回归母题4实测——六个分析卡纵向堆叠后用户直接说"人都麻了"；胶囊切换（源自 p2_fest_spend_dist_chart 的胶囊勾选式）+ 大小结论分层，让"模块一个大结论、各数据一个小结论"的层级一眼可读。

**How to apply:** 实现范式=`X3_深海世界杯_框架回归/_gen_母题4.py` 的 .bigcon/.chips/.chip/.view/.vc CSS+JS（自包含无依赖，直接抄）；配套规则=模块数据列序必带付费率三件套（见 [[feedback_module_metrics_payrate]]）。**页面用语严谨**：分析口头语不进报告文案（"对打"→"历史数据对比"，2026-07-16 用户纠正）。
**独立单模块回归页两个必备件（2026-07-21 大富翁页被用户点名补齐后立规）**：①**设计回溯归因章**——逐件对账"当初为什么这么设计→实际发生了什么→判定徽章(生效/部分错位/证伪)"，设计意图去开发案 topic/策划案溯源，光有数据现状没有设计对账=浅；②**大结论逐点带章节跳转**（con-link 指向支撑章，动作表的依据列也指向具体章节）。**设计回溯章定形=三支思维导图（同日用户追加："思维不至于太散"）**：<b>礼包设计</b>（逐件使命对账）/<b>流程体验</b>（触达漏斗[活跃→触达→参与→付费]+道具使用漏斗[发放→消耗/产出→回收率]+进度墙+子活动）/<b>数值设计</b>（免费投放量是否符合预期+兑换商店回收率+价位带+同价互踩），根+三支+叶卡带判定徽章；**叶卡=名称+徽章+一句话结论+「→图名」锚点跳转，禁长文**（同日用户纠："字太多，一句话接跳转"）——详细论证放各章，导图只当索引。实现范式=`_gen_大富翁回归.py` v3（design_mindmap()+.mm-* CSS + .bigcon a.cl + BACKTOP）。
